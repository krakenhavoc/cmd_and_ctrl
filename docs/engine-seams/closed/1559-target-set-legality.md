**Target-set legality** (#1559, CR 601.2c / 608.2b, [ADR 0019 amendment 2026-09-24](decisions/0019-structured-targeting.md)) — a rule over the chosen SET of a clause's targets, which `TargetSpec.CardOK` judging each candidate alone could never say. `TargetSpec.Different *TargetDifference{Label, Key}` is a pairwise-distinct key (`game/target_set.go`), built with `effects.EachDifferentManaValue()`, `EachDifferentController()` and `EachDifferentName()` and attached with `.EachDifferent(…)`. **Announce** refuses a set with a repeated key as `ErrIllegalTarget` carrying the printed rule; **resolution** (CR 608.2b) re-judges the survivors — a pick that left is dropped alone, and two survivors that now share a key are both illegal (the weaker reading; neither is preferred); **fillability** (CR 603.3d, the cast offer) counts keys rather than candidates; a **retarget** (CR 115.7c) may not move a slot onto a key another slot holds. The **enumerator** prunes colliding sets inside its expansion, cast and `pick_target` alike, and the **wire** ships `legal_targets.different {label, keys}` so the client picker greys and refuses a colliding candidate and says the rule in its banner. The same PR added `TargetSpec.ManaValueAtMostX` — "with mana value X or less", bound to the announced X at cast and again from `StackItem.XValue` at resolution, shipped with `mana_values` for the client to narrow by — because Agadeem's Awakening prints both halves. **Cards:** Agadeem's Awakening and Behold the Sinister Six! are new and `full`; Run Away Together drops its caveat and is `full`; Eerie Ultimatum and Windgrace's Judgment each lose their resolution-time dedup and keep one narrower caveat (untargeted-in-print, and the per-opponent binding, respectively). **Triaged out:** Molten Primordial's "for each opponent, up to one target creature that player controls" is one clause per opponent binding its pick to that player, built with the existing `TriggeredAbility.TargetsFrom`; it ships `full` in the same PR. **Still open:** a set rule on a COST (Transmutation Font's sacrifice of differently named tokens), on the set-of-sacrificed-permanents row.
