**Untap holds: "doesn't untap … for as long as you control ~ / ~ remains tapped"** (#1313, CR 611.2b / CR 502.3, [ADR 0058 amendment 2026-09-23](decisions/0058-doesnt-untap.md), building [ADR 0070](decisions/0070-untap-step-choices.md) Decision 6): ADR 0058 Decision 8 said these need "a per-source linked-object field". They do not. The effect is about the TARGET, and the target already carries a per-object list of reasons it will not untap. `UntapSkip` gains `While *Duration` (ADR 0063's type, so one `durationExpiredLocked` decides when it ends). With `While` set, the entry is a HOLD: `untapSkippedForLocked` reads it at every untap step of the permanent's controller, `consumeUntapSkipsLocked` never uses it up, and `sweepUntapHoldsLocked` drops it at the end of the first layer pass after its duration ends. That pass runs after layer 2 is materialised, so losing control of the source and regaining it does not revive the hold (the Dungeon Geists ruling). `WhileSourceRemainsTapped` is a new `DurationCondition`. The hold is cloned, snapshotted (`nextUntapSkips[].while`) and cleared on a zone change by the code that already does this for the one-shot marker. It projects as `CardView.no_untap.static`, including face-down, so the badge, the footer, the heuristic and the auto-tapper's `Frozen` ordering read it with no new wire field. Card helpers: `TapAndHoldWhileYouControlThis`, `TapAndHoldWhileThisRemainsTapped`, and `DoesntUntapWhile` for any other duration. Proof cards: Ty Lee, Chi Blocker (prowess is still #706), Dungeon Geists, Tidebinder Mage, and Rust Tick and Amber Prison, which lose their tap-ability caveats. Writable next: Merchant Raiders, Time of Ice. Icefall Regent still waits on a cost-modifier shape for "spells that target this cost {2} more". Out of scope: Spider-Woman, Secret Agent's "can't become untapped" (an untap-primitive rule, like stun), and the "for as long as you control ~ and ~ remains tapped" control effects (Willow Satyr, Rubinia Soulsinger, Hivis of the Scale).
