**Emblems that restrict players** (#1899, [ADR 0109](decisions/0109-rule-gates-land-types-mana-and-cost-components.md) §5, PR 6) — an emblem's abilities function in the command zone (CR 114.4), but the rule gates walked only the battlefield, so an emblem's "can't cast" was dead text. `effects.EmblemSpec` now carries `CastRestrictions`, `LandPlayRestrictions`, `GameEndGates` and `UntapCaps`, the `Spec` slots of the same names under the same Register guards, and each gate (`CastGateLocked`, `LandPlayGateLocked`, the game-end gates, the untap caps) walks every seat's emblems beside the battlefield with the emblem as the source, so "your opponents" is its owner's (CR 114.2). The action, the legal-move enumerator and the view already share each gate, so all three see an emblem with no caller changed. Narset's emblem is deliberately not a `CastBanRule`: that is a record stored on each banned player, invisible on the board, and nothing would end it when the emblem's owner leaves the game (CR 800.4a). Two delayed-trigger keys are new on-disk vocabulary: `cast/you-next-cast-from-hand` and `rebound/the-spell-you-just-cast`. **Cards:** Narset Transcendent and Dovin Baan (Full). **Moved to other rows:** Gideon of the Trials, whose emblem is ready, waits on the chosen-source shield row for its +1 (ADR 0108 PR 6).
