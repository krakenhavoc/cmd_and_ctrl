**Exiling a card until something happens** (#1729, CR 610.3, CR 725.4, CR 800.4a) — the "until" return is CR 610.3's second one-shot effect, created immediately after the event, and no longer a triggered ability on the stack. `game.UntilReturn` is the record, kept in `Game.DelayedTriggers` with `Until` set so it clones, snapshots and shows on the wire with everything else still owed; `effects.ExileUntil` is the one card-side primitive. An event-keyed "until" (Palace Jailer's "until an opponent becomes the monarch") is made due by the `untilReturns` listener; "until this leaves the battlefield" (Ossification, Hostage Taker, Sheltered by Ghosts) is due once its object is no longer on the battlefield, a structural test, so a source that leaves the game with its owner counts though that emits no zone-change event (ADR 0060). `resolveUntilReturnsLocked` performs every due return together (CR 610.3d) before the state-based actions and before any player receives priority ("Nothing happens between the two events, including state-based actions" — the Hostage Taker ruling). Because it is not a trigger, the record does not leave the game with its controller (CR 800.4a/d), so Palace Jailer's creature comes back when its controller leaves wearing the crown and CR 725.4 hands it to an opponent, and Hostage Taker's card comes back when its owner leaves. CR 610.3a/b is `UntilEventHappenedForEffect`, asked before the exile, so an Ossification removed in response no longer exiles its target for good, and an opponent crowned in response to Palace Jailer's trigger means nothing is exiled. Snapshot: three additive `delayedTriggers[]` keys (`until`, `untilLeaves`, `due`) and a new body key, `until/return-to-battlefield`, which an older binary refuses. The old leave triggers stay as legacy rows that fire only for a card exiled before this change. **Cards:** Palace Jailer drops its caveat and is Full.
