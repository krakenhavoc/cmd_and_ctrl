**A replacement event for copying a spell** (#5918, CR 707.10 / 614.1a / 616.1) — copying a spell is now a replaceable event, `game.RepEventCopySpell`, opened once per copy INSTRUCTION before any copy exists (`game/spell_copy_event.go`), the way `RepEventCreateTokens` is one per creation instruction. Every spell copy the engine makes goes through it: `CopySpellTimesForEffect(game.SpellCopy)` is "copy it N times" (storm, replicate, "copy that spell twice"; `effects.CopySpell` with its `Count` is one instruction now, not N), the one-copy doors (`CopySpellForEffect`, `CopyLastKnownSpellForEffect`, `CopyLastKnownSpellGainingKeywordsForEffect`) are one instruction each, so casualty and conspire make one per paid cost (CR 702.153b / 702.78b), `CopySpellRetargetedEachForEffect` is "copy that spell for each other creature" (CR 707.10e; Precursor Golem, Mirrorwing Dragon, Zada and Feather share `copySpellForEachChosenInOrder`) as ONE instruction, and Chef's Kiss's `CopySpellKeepingTargetsForEffect` is one too. A card copy that is then cast (CR 707.12) is a cast and not part of it. `ReplacementEvent.CopyOneMoreWithNewTargets` adds a copy that is always offered new targets (CR 707.10c), made after the instruction's own the way they are made (its except clause, a keyword it gains); a copy made "for" an object starts from the original spell's targets. The window settles inline (`mustSettleNow`, as a dice roll's does): the only replacements of the kind add copies and adding commutes, so the CR 616.1 order cannot change the count, and each applies once (CR 614.5), so two Staffs add two. Nothing outlives the call, so the snapshot is unchanged: each copy that asks for targets is its own queued copy frame, already a restore point. **Cards:** Twinning Staff (Full).
