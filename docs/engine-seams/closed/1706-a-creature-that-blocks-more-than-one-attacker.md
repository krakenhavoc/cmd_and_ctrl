**A creature that blocks more than one attacker** (#1706, CR 509.1a/b and 510.1d, [ADR 0045 amendment 2026-09-28 (#1706)](decisions/0045-combat-restrictions.md) Decisions 60–63). "Can block an additional creature each combat", "an additional N creatures" and "can block any number of creatures" are a per-blocker capacity on the effective characteristic (`Characteristic.AdditionalBlocks` / `BlocksAnyNumber`, read by `game.BlockCapacity`), written by layer statics (`effects.CanBlockAdditional`, `effects.CanBlockAnyNumber`). A blocker maps to a set of attackers: `Card.BlockingTarget` stays the first and `Card.AlsoBlocking` holds the rest, and the block validator, the whole-combat limits and the CR 509.1c requirement search all read a blocker → attackers assignment. A declaration entry ADDS an attacker to a blocker with room, re-points an ordinary blocker as before, and is refused with `illegal_block` / `blocker_capacity` past the capacity; menace still needs two creatures, a limit counts the creature once, and "blocks each combat" is one requirement however many attackers it takes. A blocker still blocking two or more attackers divides its combat damage among them through the reused damage-assignment prompt (`blocker_divides`, free split, no trample). The lock-in announces one `EventBlock` per pair numbered in `Amount`, so "whenever this blocks" (CR 509.3a) fires once. The wire adds `CardView.blocking_targets`, `block_capacity` and `blocks_any_number`; the snapshot adds `alsoBlocking` and `announcedAlsoBlocks`, and an older file restores its single block. **Brave the Sands** and **Hundred-Handed One** lose their caveats and ship `full`; **Palace Guard**, **High Ground**, **Guardian of the Gateless**, **Two-Headed Giant of Foriys**, **Wall of Glare**, **Echo Circlet** and **Watcher in the Web** are new and `full`. **Still open:** "can block an additional creature this turn" and "can block any number of creatures this turn" from a resolving spell or ability (Coastline Chimera, Mounted Archers, Give No Ground, Valor Made Real) need an ADR 0041 data-record mod, and "blocks each attacking creature if able" (Blaze of Glory) a requirement kind. Conditional statics (Kemba's Legion, Cenn's Tactician, Entourage of Trest, Foriysian Totem) are one file each with the builders here, left for a card batch.
