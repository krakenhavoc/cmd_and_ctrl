**The last counter-cost shape: an any-kind removal split across permanents** (#943, [ADR 0020](decisions/0020-activated-abilities.md) addendum 2026-09-18 §22) - `CounterRemovalCost.Counter` may be empty WITH `Among`: "Remove three counters from among other artifacts, creatures, and planeswalkers you control" takes three counters of whatever kinds are there, so the payment names a kind per permanent as well as a count. No sixth component and no second wire shape — `counter_kinds` is a parallel array beside `counter_source_ids` / `counter_counts`, sent only when the parts actually differ in kind, so a payment of one kind is byte-for-byte what a #625 client sends. The payment's set is keyed on (permanent, KIND), which is what lets one creature pay with its +1/+1 counter and its shield counter and still refuses naming one permanent twice in the same kind. One validator, one candidate walk, one enumerator arm (drain the fullest first, kinds included), one projection — the option list was already a (permanent, kind) list, so the client's many-pick modal needed no kind dropdown, only a label. `effects.Register`'s refusal of the combination is gone. **Cards:** Tekuthal, Inquiry Dominus ships, with one declared caveat that was NOT this seam — "if you would proliferate, proliferate twice instead" is a replacement of a keyword action (CR 701.34), which had no seam either until #976 built one (see the keyword-action row above); the caveat is gone and the card is `full`. Its `{U/P}` symbols are payable both ways since #971 landed the activation-time Phyrexian announcement, and its indestructible counter is CR 122.1b carried by its own static (the Vraska Joins Up posture). The old open row's count of 14 predated #625 and was never re-triaged; the component now covers all six printed shapes, so any of those cards still missing is missing for some other reason.
