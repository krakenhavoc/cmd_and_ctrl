**Combat-wide attack and block limits** (#1507, CR 508.1c / 509.1b, [ADR 0045 amendment 2026-09-24 (#1507)](decisions/0045-combat-restrictions.md) Decisions 43–45) — "no more than N creatures can attack / block each combat" and "no more than N creatures can attack you each combat". **Block half:** `game.BlockRule.Limit`, the whole-combat bound Decision 12 reserved, is a third set check in `checkBlockDeclarationLocked` (`blockLimitRefusalLocked`, `game/block_rules.go`), counted over every block stored in the combat, whichever attacker or defender, and refused as `illegal_block` / `declaration_limit` (the token Decision 8 reserved) with the printing card named; the option generator, the enumerator and the #328 signal stop offering a block once it is used, because they all run the validator. **Attack half:** `game.AttackLimit{Scope, Max}` (`game/attack_limits.go`), catalog-contributed through `CardDef.AttackLimits` / `CatalogAttackLimits` keyed by `CatalogAbilityKey`, with a structural "you" (`AttackLimitAttackingYou`, the zero value — the player, not their planeswalkers) or `AttackLimitEachCombat`. One check, `attackLimitRefusalLocked`, is run by `DeclareAttackerWith`, by `DeclareAttackersWith` (all or nothing, like the attack tax) and by `legal/combat.go` for every candidate move, before the CR 508.1a tax is priced; refused as the new `illegal_attack` / `attack_limit` frame. Both halves refuse only a declaration that RAISES the count, so a limit arriving late unmakes nothing. `effects.NoMoreThanNCanBlockEachCombat`, `NoMoreThanNCanAttackEachCombat` and `NoMoreThanNCanAttackYouEachCombat` are the constructors. **Silent Arbiter**, **Dueling Grounds**, **Crawlspace** and **Judoon Enforcers** ship `full`; **Caverns of Despair** ships with only the world-rule caveat. Mirri, Weatherlight Duelist's conditional / per-opponent variants and The Eternal Wanderer's per-planeswalker scope were built later with their cards (#1534).
