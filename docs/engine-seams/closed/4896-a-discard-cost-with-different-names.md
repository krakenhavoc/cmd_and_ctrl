**A discard cost with different names** (#4896, [ADR 0020](decisions/0020-activated-abilities.md)'s 2026-11-05 amendment, Decision 79; CR 201.2a, 201.2b, 709.4) — "Discard three cards with different names" could only be written as `DiscardN(3, …)`, which takes three copies of one card. `game.DiscardCost.DifferentNames` is the set rule as data (no route from `Game` to a func), built with `effects.DiscardNDifferentNames(n, label, match…)` and read strictly as the sacrifice clause's twin (#3940) is: a card with no name is never a candidate, and both halves of a split card count, so Fire // Ice and Fire share a name. `validateDiscardCostLocked` refuses a repeat with nothing paid (`game.DiscardNamesDiffer`); the enumerator's one payment is `game.DiscardDifferentNamesPaymentForEffect`, the cheapest N whose names differ (a small backtracking walk past split cards), and no move when the hand holds fewer than N names. The wire carries the public `discard_cost_different_names`; `DiscardCostModal` greys a card whose name is already picked, holds the confirm until the names differ and says when the hand is short of names, and the board opens it even at exactly N options. `effects.Register` allows the rule only on an activated ability's fixed count of two or more, never beside "at random", "your hand", X or the legendary-name clause, and not on a mana ability. No snapshot change. **Cards:** Ormos, Archive Keeper — Full, whose draw replacement is Laboratory Maniac's window with a `DrawInstead` body: five +1/+1 counters for each draw from an empty library, with the rest of the instruction parked behind a counter placement that can pause on a CR 616 ordering prompt.
