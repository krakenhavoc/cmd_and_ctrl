**A sacrifice batch with a continuation** (#910, [ADR 0013 §5r](decisions/0013-replacement-effects.md)): destroy, exile, bounce, tuck and mill have all reported what they did since #815 / #866 / #893; sacrifice had only the per-card call, so Living Death's second pass fired and forgot and every "sacrifice all X, then for each …" read nothing back. `sacrificeRoute(source)` is the seventh route template, built on #667's `battlefieldExitRoute` — the same battlefield-exit mover a destruction takes, deliberately WITHOUT its `Destruction` flag, so the CR 701.19 regeneration built-in can never see a sacrifice (CR 701.17a) — plus the `EventSacrifice` announcement the leg now owns (before the window, while the permanent is still there) and its own "this way" rule. `Game.SacrificeAllThenForEffect(source, ids, then)`, `SacrificeThenForEffect` (single card, "sacrifice a creature. If you do, …") and the fire-and-forget `SacrificeAllForEffect`; `sacrificePermanentLocked` is the same leg with no batch, so there is one sacrifice path and not two. A sacrifice is not replaceable (CR 701.17a) but the MOVE it makes is, so a sacrificed commander opens CR 903.9 and a leg can pause. **"Sacrificed this way" is the permanent that LEFT the battlefield**, wherever it landed — the one row where it differs from "destroyed this way" (`sacrificedThisWayLocked` vs `destroyedThisWayLocked`): CR 701.7a defines a destruction by the graveyard, CR 701.17a's sacrifice is the controller's move off the battlefield. **3 cards converted:** Living Death (pass 3 now waits for pass 2, and the creatures leave as one simultaneous exit), God-Eternal Bontu ("then draw that many cards" is the continuation's count) and All Is Dust, which lost its caveat — a Blood Artist swept by the spell sees every death including its own (CR 603.10). Slaughter the Strong rides the same helper and keeps its own, unrelated caveat.
