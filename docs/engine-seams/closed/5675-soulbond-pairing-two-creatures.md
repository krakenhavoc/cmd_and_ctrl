**Soulbond: pairing two creatures** (#5675, CR 702.95, 603.4, 707.9b) — a pair is a link written on both creatures, `game.Card.PairedWith` (snapshot `pairedWith`, additive), made by `Game.PairForEffect` and read with `Game.PairedPartner`. The keyword's two triggered abilities (CR 702.95a) are catalog rows, `effects.Soulbond(name)`, beside `PrintedKeywords: {game.KeywordSoulbond}`: each checks its intervening "if" as it triggers and as it resolves, and the partner is chosen on the "choose permanents" prompt with a floor of zero, which is the "you may" (keyed run `soulbond/pair`, so a table waiting on it is a restore point). CR 702.95e's three endings (another player gains control, it stops being a creature, it leaves the battlefield) are swept at the end of each layer recompute (`sweepBrokenPairsLocked`), so a pair that ends stays ended when control or the type comes back; phasing out ends nothing (CR 702.26d). "As long as this is paired with another creature, each of those creatures has '…'" is `effects.PairedCreaturesHave(label, grantKey)`, an ADR 0093 layer-6 grant to both creatures. "Except it … loses soulbond" needed one more piece: a copy exception that takes a printed keyword away is the copiable value `Card.LostKeywords` (`Card.LoseCopiedKeyword`, `PrintedValues.LoseKeyword`; snapshot `lostKeywords`, additive), because the keyword also arrives through the copied oracle ID's `PrintedKeywords`. The wire has `CardView.paired_with` and the client shows a PAIRED badge naming the partner (`L.pairedBadge`). **Cards:** Thundering Mightmare, Doom Weaver, Imperious Mindbreaker, Breathkeeper Seraph, Mirage Phalanx (all Full).
