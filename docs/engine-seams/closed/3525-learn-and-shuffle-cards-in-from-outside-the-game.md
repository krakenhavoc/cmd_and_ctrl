**Learn, and shuffling cards in from outside the game** (#3525, CR 701.48a, 701.24d, 400.11c, 205.3k, [ADR 0191](decisions/0191-a-sideboard-is-the-outside-the-game-pool.md) amendment of 2026-10-22) — the two things the sideboard seam still lacked. **Learn** is `effects.Learn`, the keyword action as the rules write it: "you may discard a card" (a `DiscardPrompt` with a floor of zero, so an empty hand is asked nothing), a draw for a player who did, and for one who did not a `TakeFromOutside` for a Lesson card (a spell type, read off the type line), revealed, over the sideboard or, for a deck that seated none, the card database (ADR 0198). It is the last instruction of every printing, written as a `ResolveSteps` step (or `Do(Learn{})` in a trigger or an ability) so it waits for an answer an earlier clause asked; `OnTheTargetCard` is the step for "do X to the target, then learn". **Shuffling in** is `effects.ShuffleFromOutside`: a pick of up to N cards, put on the bottom of the library unrevealed by the new `game.PutFromOutsideIntoLibraryForEffect` (the second door out of the container, beside `BringFromOutsideForEffect`), then a shuffle that happens even when nothing was chosen or the pool was closed (CR 701.24d). **The checker** lists the sideboard: `deckcoverage.Report.Sideboard` (additive, omitempty) buckets it like any card, outside `Cards`, `Counts` and `Copies`, and the decks page shows one line for it. A sideboard card is still not checked against the commander's colour identity or the banlist (ADR 0191, decision 3). A table with a learn question open is not a restore point (the prompt carries a continuation closure); the last one before the cast is. **Cards** (21, all Full): Research // Development (Development is three keyed rounds of an opponent's choice, so a table waiting on one is a restore point; a new `3/1 red Elemental` token row), First Day of Class (a delayed "whenever a creature you control enters this turn" trigger, a new each-condition), Academic Dispute, Arcane Subtraction, Cram Session, Divide by Zero, Dream Strix, Enthusiastic Study, Eyetwitch, Field Trip, Gnarled Professor, Guiding Voice, Hunt for Specimens, Igneous Inspiration, Overgrown Arch, Poet's Quill, Pop Quiz, Professor of Symbology, Rise of Extus, Sparring Regimen, Study Break. Retriever Phoenix, whose graveyard clause replaces a learn, followed once learn became a replaceable event (see "Learn is an event a replacement can apply to").
