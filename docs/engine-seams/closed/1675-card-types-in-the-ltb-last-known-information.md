**Card types in the leaves-the-battlefield last-known information** (#1675, CR 603.10a, [ADR 0027 amendment 2026-09-28, #1675](decisions/0027-attack-triggers.md)). `diedCreature(ev, g)` — the reader behind every "whenever a creature dies" card — tested `IsCreature()` on the card in the graveyard, where no continuous effect applies any more, so a crewed Vehicle, an animated manland or an animated artifact that died triggered nothing, and a creature an effect had made a noncreature still did. `EventLTB` now carries `Event.LastKnownTypes`, the leaving permanent's post-layer card types, read by the same `battlefieldExitLocked` look-back (`exitLKI`, was `combatLKI`) that stamps the #1661 combat state, so every exit route carries them with no new call site; `Event.WasType` reads them and says whether the event knows. Card side, `leftAsType(ev, c, cardType)` is the one question, and `diedCreature` plus every other dies / leaves-the-battlefield condition that tests a card type (artifact, land, artifact-or-creature, creature-you-control-left, The Ozolith, Cruel Celebrant) asks it. No new game state: the field rides the event log. **Cards:** Mahadi, Emporium Master's caveat was stale (the per-turn tally already read the CR 603.10 snapshot) and is cleared. **Still open:** subtypes and supertypes as they last existed ("whenever a Zombie you control dies" misses a granted Zombie), and controller as it last existed.
