**Earthbend, and a delayed trigger keyed to an OBJECT** (#1178, CR 701 keyword actions, [ADR 0081](decisions/0081-earthbend-and-object-keyed-delayed-triggers.md)) — twelve Avatar cards print *"Earthbend N. (Target land you control becomes a 0/0 creature with haste that's still a land. Put N +1/+1 counters on it. When it dies or is exiled, return it to the battlefield tapped.)"*, and #1178 filed it as four gaps. It is **one verb**: `KeywordActionEarthbend` joins proliferate, scry and surveil on `RepEventKeywordAction` ([ADR 0013](decisions/0013-replacement-effects.md) §5s), so the printed count rides a CR 614 window and a future "earthbend twice that much instead" is a card-side replacement rather than an engine change. Its count means a **third** thing — proliferate counts TIMES, scry and surveil count CARDS, earthbend counts **+1/+1 counters** — and it is the first action in the family that acts at a count of ZERO (`KeywordAction.actsAtZeroCount`): Rockalanche with no Forests still animates the land, which then dies to CR 704.5f and comes back tapped. The animation is **three** `ScopedStatic`s with **one** CR 613.7 timestamp and **one** duration — layer 4 adds Creature and leaves Land alone, layer **7b** (not 7a; #1178's shorthand was wrong) sets base P/T to 0/0, layer 6 grants haste — the duration being `IndefiniteDuration()` **pinned to the object**, which is CR 611.2a plus CR 400.7 plus garbage collection in one value and what makes "the haste and the animation end together" a fact about the data. The 7b bucket is load-bearing twice over: it REPLACES a printed body (Dryad Arbor earthbent 2 is a 2/2, not a 3/3) and it sets `Characteristic.PTDefined`, without which CR 704.5f skips the 0/0 whole. Counters go through `AddCounterByForEffect` (the PLACEMENT window — Hardened Scales applies; the entry pipeline is deliberately not involved) and go **last**, because the placement is the only part that can pause. The return is the new mechanism: a **CR 603.7 delayed trigger whose condition is an EVENT about one object** (`DelayedTrigger.On` + `AppliesTo`, #663, previously only ever watching a cast) — `EventLTB` whose `NewZone` is a graveyard or exile, so a Rest in Peace-style replacement that exiles a dying land still satisfies "dies **or is exiled**"; its ID is DERIVED from `{instance, EnteredBattlefieldAt}` so a second earthbend on the same object queues no second return; and it carries the first non-`UntilEndOfTurn` duration a delayed trigger has had, `Indefinite` pinned to the object so an unsatisfiable entry is swept rather than carried for the game. `Game.ReturnToBattlefieldForEffect(cardID, controller, tapped)` is the router the trigger needs, dispatching on the card's live zone over the two existing doors (each keeps its own CR 400.7 bookkeeping). **Cards:** Earthbending Lesson and Rockalanche ship `full`, and The Legend of Kyoshi's front face goes from `caveats` to `full` (#1179's earthbend caveat deleted). **Still open, and ordinary card work now**: the other nine earthbend cards each wait on something else — **exhaust** (Bitter Work, Ba Sing Se; nothing in the engine has it — filed as #1181, 41 printed cards), a reflexive "when you do" around the verb (Earth Rumble), two target clauses in one sentence (Cracked Earth Technique), per-mode targets (Sandbenders' Storm, Dai Li Indoctrination), and reading the animated land's power afterwards (Earthshape, **shipped with #1282** on `effects.Earthbend.Then` / `game.EarthbendThenForEffect`, which run once the counters have landed, including after a CR 616 counter-order prompt; since #1289 the bare land that is a 0/0 during that prompt survives it, because state-based actions wait for the resolution). **Also still open**: a per-instance return queue, which only matters the day a card can counter a triggered ability.
