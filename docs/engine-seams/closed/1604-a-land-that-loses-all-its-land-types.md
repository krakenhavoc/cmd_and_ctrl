**A land that loses all its land types** (#1604, [ADR 0109](decisions/0109-rule-gates-land-types-mana-and-cost-components.md) §2, PR 3) — "loses all land types" is a layer-4 type change (CR 205.3i, 613.1d). The new `ScopedEffect` kind `loseLandTypes` (`game.LoseLandTypesMod`, reads nothing) and its static form `effects.LosesAllLandTypes` both call `Characteristic.LoseLandTypes`, which removes every one of CR 205.3i's seventeen land types and keeps every other subtype (CR 205.1a), so a Dryad Arbor is still a Dryad. It is not CR 305.7: it removes no ability by itself. The basic land types' intrinsic mana abilities go with the types (CR 305.6). Every printed use goes on to say "and abilities and has …", which is the same effect's layer-6 half: `game.LoseAllAbilitiesMod` and a grant in the same record, or the static `effects.LosesAllAbilitiesAndHas`, with the removal applied before the grant. The land-type chip lists a `loseLandTypes` record with what that effect took and gave (`No land types, no abilities, "{T}: Add {C}." for as long as it has a blight counter on it — Ultima, Origin of Oblivion`). Alpine Moon's chosen name became the first chosen name a static ability reads, so choosing one now bumps the layer version, and it is read by `game.PermanentHasName` (the name of the face that is up, CR 712.8f) because "a nonbasic land card name" is judged by the named face (CR 201.4a, 201.4d). A v7 corpus fixture holds the new kind. **Cards**: Ultima, Origin of Oblivion (one record timed by `WhilePinnedHasCounter{blight}`, and its "add an additional {C}" triggered mana ability), Lithoform Blight and Alpine Moon.
