**A chosen named option as the permanent enters** (#1572, CR 614.12, [ADR 0071 amendment 2026-09-27](decisions/0071-designations-that-switch-abilities-on.md)) — "As this enchantment enters, choose Khans or Dragons. • Khans — … • Dragons — …", the Siege cycles' anchor words. `Card.ChosenOption` is the as-enters family's fifth member (after `NamedTribe`, `ChosenColor`, `ChosenPlayer` and `ChosenName`) with their lifecycle verbatim: per instance, cleared at both CR 400.7 sites, carried by clone and the snapshot, not copiable. It is written by `Game.QueueChooseOptionAsEntersForEffect`, an ordinary `option_pick` with one option per printed word, so the gate, the enumerator, the wire and the client modal needed nothing. What reads it is ADR 0071's gate, not card code: `DesignationChosenOption` (`game.ChosenOptionIs(word)`, card side `ChosenIs` / `WhenChosen` / `StaticWhenChosen`) drops the unchosen line from the four ability accessors, and an unanswered prompt matches neither word. `EventOptionChosen` bumps the layer version and is narrated as `choose_option`; `CardView.chosen_option` carries the word. Card side: `ChooseOptionAsEnters(label, options...)`. **6 cards, all `full`:** Frostcliff Siege, Palace Siege, Citadel Siege, Barrensteppe Siege, Outpost Siege, Frontier Siege. Still waiting: Windcrag Siege, whose Mardu line is a trigger doubler and `game.TriggerDoubler` has no designation gate.
