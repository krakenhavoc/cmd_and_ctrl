**Turning a face-down permanent face up as an effect** (#2590, [ADR 0082 second amendment 2026-10-07](decisions/0082-casting-face-down-and-turning-face-up.md), CR 708.8 / 701.40b) — `Game.TurnFaceUpForEffect(source, actor, id)` turns a face-down battlefield permanent face up for free, through the same tail as the CR 116.2g special action (`finishTurnFaceUpLocked`): the copiable values revert, it is the same object, CR 613.7f's timestamp is renewed, every seat becomes a knower and `EventTurnedFaceUp` fires after the state is cleared, so "when this is turned face up" and Growing Dread see an effect's turn exactly as they see the action's. What an effect does not pay is the cost, and so not the megamorph counter either (CR 702.37b owes it only when the megamorph cost was paid). `game.CanTurnFaceUpForEffect` is the one refusal rule: a manifested or cloaked card that is not a creature card stays face down (CR 701.40b / 701.58b); a permanent an Ixidron left with no way back up, which the special action cannot reach, CAN be turned by an effect (CR 708.7 withholds the action, not the effect). The event's `Actor` is the effect's player and its `Source` the effect's object (the permanent itself for the special action), which is how the new `turn_face_up` log line is written only for an effect's turn. Card side: `effects.TurnFaceUp`, the `effects.FaceDown()` target predicate, and three cards shipped `full`: Hauntwoods Shrieker (reveal, then a yes/no), Zimone, Mystery Unraveler (the existing `Game.ResolvedThisTurn` tally is "the first time this ability has resolved this turn") and Staff Room (a turn-or-counter choice asked only when the creature can be turned up).
