**Exile instead if it would die this turn** (#1886, [ADR 0108](decisions/0108-turn-scoped-effects-object-history-and-damage-shields.md) §1, PR 1) — "if it would die this turn, exile it instead" (CR 614.1a, 700.4) is a `ScopedEffect` replacement kind, `exileIfWouldDie` (`game.ModExileIfWouldDie`, reader `replacement`, reads nothing), on a move from the battlefield to a graveyard and nothing else: a bounce, an exile or a tuck is untouched, and a sacrifice or zero toughness is a death and is replaced. `Game.ExileIfItWouldDieThisTurnForEffect` pins it to one object until cleanup (CR 400.7, 514.2), so a flickered creature comes back free of it; `Game.ExileIfCreaturesWouldDieThisTurnForEffect` writes it over a live set (CR 611.2c) with the new `ScopeCreatures` ("If a creature would die this turn", Flaying Tendrils) or `ScopeOpponentsCreatures` (Malicious Eclipse), reading the dying permanent's type and controller as it would die. Two records on one dying creature are one modification, so no CR 616 question is asked. The card side (`effects/exile_if_dies.go`) follows the printed wording: `ExileIfItWouldDieThisTurn` for "if that creature would die" and "if it's a creature" (the spell's effect, registered whatever the damage did — the Disintegrate ruling), and `ExileIfDealtDamageWouldDie` for "a creature dealt damage this way", a continuation on the new per-recipient damage walk `game.DealDamageEachEachThenForEffect` that marks only a recipient dealt more than 0. The view shows an EXILED IF IT DIES chip on a marked permanent (`CardView.exiled_if_it_dies`) and a banner line for a scoped record (`GameView.exile_if_creatures_die`). A v7 corpus fixture holds every shape.
