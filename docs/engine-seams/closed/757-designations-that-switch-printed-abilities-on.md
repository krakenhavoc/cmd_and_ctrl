**Designations that switch printed abilities on** (#757 / #759, [ADR 0071](decisions/0071-designations-that-switch-abilities-on.md)): Class levels (CR 716.2), solved Cases (CR 719.3) and station charge-counter thresholds (CR 721.2) are ONE gate — an `ActiveWhen Designation` field on `StaticAbility`, `TriggeredAbility`, `ActivatedAbilityShape` and `CostModifier`, with one predicate (`Designation.Active`) and one filter, evaluated in the four object-level accessors that sit on ADR 0046's `CatalogAbilityKey` (`StaticAbilitiesForCard`, `TriggersForCard`, `ActivatedAbilitiesForCard`, `CostModifiersForCard`). An inactive ability is ABSENT from what the object hands back, so the layer pass, the trigger harvester, the activation path, the cost pricer, the legal-move enumerator and the wire cannot disagree about whether it exists. `Card.ClassLevel` (a designation, not a counter, and not copiable — CR 716.2c) and `Card.Solved` are both carried by clone and snapshot; `EventClassLevel` and `EventCaseSolved` bump the layer version, and charge counters already did. Level-up is an ordinary activated ability from one constructor (`LevelUp`, carrying CR 716.2d sorcery timing and 716.2e "only from level N-1"); "To solve" is one constructor (`ToSolve`) with the CR 603.4 intervening if checked twice. **Cards:** Wizard Class and Case of the Shattered Pact go Full; Fortune Teller's Talent (#333) registers with two caveats on library-top cast (#765) and The Seriema (#337) with one on the station cost (#758). Still open above: Rooms (CR 709.5). The station ability's cost closed with #759 (see Station, above). **#1321** ([ADR 0071 addendum 2026-09-23](decisions/0071-designations-that-switch-abilities-on.md)) added a fifth designation, `DesignationHarnessed` (CR 701.64 / CR 702.186b's "∞ — [Ability]"), the same three pieces `DesignationCaseSolved` is — `Card.Harnessed`, `HarnessForEffect` / `IsHarnessed` (idempotent, since CR 701.64a is worded "if … isn't … it becomes" rather than a legality restriction), `EventHarnessed` bumping the layer version and silent on the public log (board state is visible via `CardView.harnessed`). The Mind Stone is the proof card and ships Full: indestructible, `{T}: Add {W}`, `Harness` (a plain `Plus(ManaCost, TapCost)` activated ability with no `ActiveWhen`/`Condition`) and the ∞ end-step flicker (Thassa, Deep-Dwelling's blink one clause wider, `ActiveWhen: Harnessed()`).
