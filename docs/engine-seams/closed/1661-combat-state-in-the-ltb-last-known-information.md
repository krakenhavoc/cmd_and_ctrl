**Combat state in the leaves-the-battlefield last-known information** (#1661, CR 603.10a / 506.4, [ADR 0027 amendment 2026-09-28](decisions/0027-attack-triggers.md)). A permanent leaving the battlefield is removed from combat, and the exit cleared `Card.AttackingTarget` / `BlockingTarget` before any watcher's trigger condition ran, so only the dying card's own triggers had a snapshot and that snapshot carried no combat state. `EventLTB` now carries it: `Event.AttackingTarget` (the player, planeswalker or battle it was attacking), `Event.BlockingTarget` (the attacker it was blocking) and `Event.Blocked` (it was a blocked attacker, CR 509.1h). `battlefieldExitLocked`, which every battlefield exit runs, reads them before anything clears them and hands them back for the three `EventLTB` emit sites to stamp, so combat damage, a removal spell mid-combat, a sacrifice, a bounce and the sandbox move all report the same facts; a creature removed from combat first (a control change) reports none. No new game state: the facts live on the event log, which Clone and the snapshot already carry. Card-side reads are `diedWhileAttacking(ev, g)` and `diedWhileBlocking(ev, g)`. **Cards:** Kardur, Doomscourge is now `full`; Garna, Bloodfist of Keld moved off an event-log walk that missed attackers put onto the battlefield attacking; Death Tyrant and Ares, God of War are new. **Still open, and a different shape:** "attacking or blocking ALONE" (Thijarian Witness) needs the combat's other participants, and "goaded attacking or blocking creature" (Baeloth Barrityl) waits on a static goad.
