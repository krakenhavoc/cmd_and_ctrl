**Costs that only some mana can pay: one mana of each colour on X, and a source restriction on an alternative cost** (#2575, CR 118.9 / 601.2h / 609.4b, [ADR 0040](decisions/0040-mana-pipeline.md)'s amendment of 2026-10-22) — the last two shapes of the "Costs that only some mana can pay" row. ONE OF EACH COLOUR: `ManaSpendOnly.Distinct`, built with `effects.SpellSpendOnlyColoredOnXOneOfEach()`, is folded by `foldSpendOnly` into one single-colour requirement per colour of a subset of WUBRG (and an unpayable one past five), and `costAsPaidByLocked` chooses the subset: the first the floating pool pays, else the first the pool and an auto-tap plan pay under the payer's exclusions (`costAsPaidByExcludingLocked`), else the first. The cast's auto-tap and payment, the assisted cast, `internal/legal`'s probe and the `/autotap` preview all read it there, so no solver changed and they cannot disagree. SOURCE ON AN ALTERNATIVE COST: `AlternativeCost.SpendOnlySources` is read into `ManaSpendContext.SourceOnly` by `ManaSpendForCastParams` when the cast claims that offer, and the enumerator now builds its context from the announcement, so the pool, the auto-tapper, the bot and the preview hold the payment to it as they hold a card-wide restriction. **Cards:** Emblazoned Golem and Security Rhox (Full). Soul Burn was already Full (#3941).
