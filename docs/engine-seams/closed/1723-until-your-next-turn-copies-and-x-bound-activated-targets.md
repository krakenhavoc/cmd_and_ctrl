**"Until your next turn" copy effects, and X-bound targets on an activated ability** (#1723, CR 611.2b, CR 602.2b, [ADR 0043 amendment 2026-09-28 (#1723)](decisions/0043-copy-effects.md), [ADR 0019 amendment 2026-09-28 (#1723)](decisions/0019-structured-targeting.md)). Two small seams #1720's builder found, closed together because both are one-field additions with no new engine machinery. **First:** `effects.BecomeCopy.Indefinite bool` covered only "until end of turn" and no stated duration; `Duration CopyDuration` is now a three-value enum adding `CopyUntilYourNextTurn`, which `Apply` turns into `game.UntilYourNextTurnDuration(ctx.Controller())` — an engine kind that already existed and that `durationExpiredLocked` already swept generically, so nothing there changed. **Second:** `TargetSpec.ManaValueAtMostX` ("X or less") gets an exact twin, `ManaValueEqualsX`, sharing the same `xBound` / `xBoundSet` bind-and-recheck machinery with `==` instead of `<=`; and `effects.Register`'s `checkNoXBound` now takes an `xAvailable bool` (`a.Cost.DemandsX()` for an activated ability's clause, still `false` for a trigger's) instead of refusing every non-spell owner outright — the announce and CR 608.2b re-check paths needed no change at all, since `ActivateCatalogAbility` and `itemAnnouncedClauses` already ran the same bind generically over "the announcement," ability items included. The one real piece of new logic is in the bot enumerator: "with mana value X" is NOT monotonic in X the way "or less" is, so `internal/legal/abilities.go` cannot pick the single largest affordable X the way every other `{X}` ability does — it tries every X from the floor up and keeps only the `(X, target)` pairs that are actually legal, the pairwise form of #544's rule. **Cards:** Shapesharer (new, `full`) uses the first half; Lazav, the Multifarious (new, `full`) uses the second (and the first, indefinitely, for its own copy). **Still open**, named in the ADR 0043 amendment (#1593) this narrows: Mizzium Transreliquat's second ability and Dimir Doppelganger and Lazav, Dimir Mastermind's indefinite copies were already shipped before this issue; last-known copiable values of a permanent that has left the battlefield remains unaddressed.
