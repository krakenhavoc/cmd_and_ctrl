**Three cost components: return a permanent to hand, a sacrifice count the activator announces, and a discard on a mana ability** (#1213, CR 118.3 / CR 601.2h / CR 602.2b, [ADR 0073 amendment 2026-09-22](decisions/0073-optional-additional-costs-and-the-cast-gate.md)) — three rows, one vocabulary. Each component is ONE struct with ONE options walk, ONE payability predicate, ONE validator and ONE payer, shared by the engine, the protocol view's picker and the legal-move enumerator, which is the #544 invariant `counter_cost.go` and `tap_others_cost.go` already keep. **`game.ReturnToHandCost`** (`return_cost.go`, `AbilityCost.ReturnToHand`, wire `return_ids`) is `TapOthersCost` one verb over — `Count`, a `TargetSpec` filter, `ExcludeSource` for the printed word "another" — and it is deliberately neither `SacrificeOther` with a destination (a sacrifice emits `EventSacrifice` and feeds Blood Artist; a return does not) nor `BounceToHandForEffect` (that is the effect verb; paying a cost is not an effect). It pays through the one battlefield-exit door with **`zoneRoute.MustSettleNow`**, the same bit the cost discard sets and for the same reason: CR 601.2h pays an announcement's costs as one indivisible step, so a commander returned as a cost takes its owner's hand without opening the CR 903.9 prompt. Paid with the sacrifices, before the stack item is built, so a leaves-the-battlefield trigger sits ABOVE the ability (CR 603.3b); the source is a legal pick when the filter admits it (Master Transmuter returning herself), so the activation path drops its `source` handle afterwards exactly as it does after a sacrifice. **The variable sacrifice count** is an ANNOUNCEMENT rather than a clause shape: `SacrificeCostBounds(spec, x)` reads the two printed forms — an open count (`Min` ≥ 1, no ceiling — "sacrifice one or more artifacts") and `CountFromX` ("Sacrifice X Treasures") — and `SacrificeCountLegal` is the one predicate the validator, the view's picker bounds and the enumerator's payment walk all read. `CountFromX` makes `AbilityCost.DemandsX()` true even with no `{X}` in the mana component, which is the one sentence of `activated.go` this rewrote; `XSlots()` is untouched, so Grim Hireling's `{B}` is `{B}` at every X, and `Register` refuses a cost that puts `{X}` in BOTH places. **`PaidCost.Sacrificed`** records how many the announcement actually paid, for `CountersRemoved`'s reason (#789): by resolution the permanents are in graveyards and nothing on the board could count them; `ctx.Sacrificed()` is the reader. `effects.Register`'s #747 guard narrowed rather than disappeared — still refused are a floor below one, a ceiling below the floor, `AllowSame`, `Players`, and `CountFromX` where there is no X to announce (a mana ability, CR 605.3b; a cast, whose flat payment lists need a fixed width). **`effects.ManaAbilityCost.DiscardCards`** is #660's component with a second owner, like `SacrificeOther`, `RemoveCounters` and `TapOthers` before it: `discardCardsLocked` with `DiscardCauseCost`, so `EventDiscardCard` fires once per card, the CR 614 window runs over the exit and madness (CR 702.35a) sees it without learning that mana abilities exist. The **auto-tapper never plans one** (`autoTapAbilityFor`), on the ground the life cost and the tap-others cost already fail: which card to pitch is a decision, and the planner makes none. Bot enumeration is capped at `legal.maxEnumeratedVariableCounts` (3) counts per variable cost, documented in [docs/bot.md](bot.md) beside `maxEnumeratedCostPayments`, with each payment ordered by the seat's own `OrderCostFuel` price so the counts nest. **7 cards, all `full`:** Meloku the Clouded Mirror, Master Transmuter, Quirion Ranger and Wirewood Symbiote (the return cost); Radiant Lotus and Grim Hireling (the two variable-count forms); Skirge Familiar (the mana-ability discard). **Still open, and on their own rows:** Mox Diamond's entry-replacement discard — a PROMPT seam rather than a cost component, because an entry replacement has no announcement to pay at, and #1198's `EntryHandReveal` is the branch it wants with the card moving instead of being revealed. One card, so it is noted on batch issue #295 rather than given a row of its own; last-known information for an effect that reads the sacrificed permanents themselves ("the sacrificed creature's power"), which no card on the row asked for; and a VARIABLE tap-others count (Secluded Starforge, Apothecary White), which #758 stated out of scope and which should copy `SacrificeCostBounds` when it lands.
