**An attack requirement gated on its source attacking** (#5840, CR 508.1d) — `AttackRequirement.IfSourceAttacks` makes a requirement exist only in a declaration that has its `Source` attacking, and never on the source itself: CR 508.1d's "or that it attacks if some condition is met". `attackRequirementsOfLocked(c, assign)` reads it against the declaration being judged, so reach counts it only once the source is staged and never for a completion that would add the source. Declaring nothing, or attackers without the source, owes nothing; staging the source raises reach by every free attack the others could make, and the checkpoint (the active player's pass, and `AdvanceStep` leaving the step) refuses until they make them. Nothing undeclares an attacker, so every accepted verb still keeps reach, and the source's slot under an attack limit is counted as for any creature (it is refused where it would take Zurgo's one slot under Silent Arbiter). `MustAttackForEffect` and the enumerator follow, so a bot that declares the source is offered the others' attacks as its always-legal answers and no pass. The refusal reads "Grizzly Bears must attack if able, because Viashino Bey is attacking." Card side: `effects.IfThisAttacksAllYourCreaturesAttack()`. **Card:** Viashino Bey (Full).
