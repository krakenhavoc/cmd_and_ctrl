**Commander ninjutsu: a non-cast exit from the command zone** (#1278, CR 702.49c / CR 903.8 / CR 903.9 / CR 400.7, [ADR 0020](decisions/0020-activated-abilities.md)'s 2026-09-24 amendment, Decisions 38–40) — the one piece #1227 left. `effects.CommanderNinjutsu(cost)` is `Ninjutsu(cost)` with `Zones = {ZoneHand, ZoneCommand}`, and again not one line of `ActivateCatalogAbility` changed (the command zone has been scanned, gated by CR 113.6 and owner-checked under CR 108.4 since #660). **`Game.PutFromCommandZoneOntoBattlefieldForEffect`** is the hand door with the command zone for the hand: `startEntryBatchLocked` admits `ZoneCommand` as a `BatchEntry.From`, so the arrival runs the one CR 614 entry window and the CR 506.3c attacking stamp unchanged, and **keeps its instance ID** because `Player.CommanderCasts` is keyed by it. The bookkeeping the issue asked about is all negative and all pinned: no CR 903.8 tax and nothing added to it (the tally is bumped by the cast path alone), no CR 903.9 prompt on the way IN (`commanderZoneReplacement` is destination-only and the battlefield is not one of its four), and `Card.IsCommander` rides the card so the shared exit primitive from #539 offers CR 903.9 on the way OUT and combat damage counts as commander damage. **`ninjutsuEnter` now checks the OBJECT** (`Card.ObjectEpoch` against `StackItem.SourceEpoch`), because a commander discarded in response takes CR 903.9's command zone — a zone the ability also names, same ID — and by CR 400.7 the ability has lost her; this tightens plain ninjutsu the same way. **No wire change**: `abilityZones()` and `stampZoneAbilities` have walked the command zone since #1221. Client: `CommandZone.svelte` hands `zone_abilities` to its card (right-click popover, as the hand) with an `ability` hint beside `cast`. **1 card, `full`:** Yuriko, the Tiger's Shadow — the only non-joke printing. **Still open:** a commander returned AS the ninjutsu cost goes to hand without the CR 903.9 offer, because cost exits cannot pause (`MustSettleNow`, the posture every cost exit takes) — #1397.
