**State triggers** (#1858, CR 603.8, [ADR 0107 §1](decisions/0107-state-triggers-rebound-disturb-and-damage-prevention.md)) — "When you control no Islands, sacrifice this creature", "When there are five or more plot counters on this enchantment". `TriggeredAbility.State` names a condition over the board, the source and its controller, filed in a package-level registry (`RegisterStateCondition`) that no `Game` reaches, so the row holds a key and no func; a row that declares one watches no event, and Register refuses it with an unregistered key, `Watches`, a `Build`, no `Effect` or another zone, so its stack item is always keyed (`catalog/triggered`) and a table with one waiting is a restore point. Per owner decision 1 the engine asks every battlefield permanent's state triggers after every event it emits and in each pass of the CR 704.3 loop, so a state that lasts a moment inside a resolution still triggers, as CR 603.8's own example says; combat damage (CR 510.2) and a state-based-action sweep, which the rules see as one event and the engine emits in pieces, hold the per-event check until they finish. The CR 603.8 latch is derived, never stored: the ability is latched while the trigger queue, an open announcement prompt, the stack or the still-open resolving slot holds an item of the same row from the same object (CR 400.7), and a copy of the ability does not latch it. The registry records which catalog keys carry a state trigger, so the walk is a map lookup per permanent and the layer cache is caught up only when a candidate is on the battlefield. Helpers: `WhenYouControlNo`, `WhenYouControlNoOther`, `WhenThereAreNo` and `WhenYouControlAtLeast` over ADR 0107's shared `game.PermanentQuery`, `WhenThisHasAtLeast` and `WhenThisHasNo` for counters, and `WhenState`. No closure route and no snapshot field: the key lives only on catalog rows, which the running binary rebuilds on restore. **Cards** (43, all Full): Afiya Grove, Barbarian Outcast, Covetous Dragon, Dark Depths, Darksteel Reactor, Deadly Designs, Drop of Honey, Emperor Crocodile, Endangered Armodon, Endrek Sahr, Master Breeder, Force Bubble, Garruk Relentless, Homarid, Last Laugh, Lurebound Scarecrow, Lurking Jackals, Mana Vortex, Mazemind Tome, Opal Avenger, Plague Boiler, Porphyry Nodes, Serendib Djinn, Skeleton Ship, Synod Centurion, Task Mage Assembly, Tethered Griffin, The Millennium Calendar, Tidal Influence, Transcendence and Veiled Crocodile, and with ADR 0107 §2 the serpents Bog Serpent, Dandân, Giant Shark (its block trigger reads ADR 0107 PR 5's `DealtDamageThisTurn`), Gorilla Pack, Island Fish Jasconius, Manta Ray, Marjhan, Merchant Ship, Pirate Ship, Ronom Serpent, Sea Serpent, Slipstream Serpent and Vodalian Knights. Bomb Squad's state trigger about each creature followed (see "State triggers about each of several objects"). **Moved to other rows:** Rune-Tail on flip cards (#1892), Phylactery Lich on an as-enters counter on another permanent (#1893), Seasinger on a two-condition control duration (#1894), City in a Bottle on a land-play restriction (#1895), Immortal Coil on "damage prevented this way" and Nine Lives on a prevention effect's CR 615.12 additional effect (both #1860) and Kukemssa Serpent on a land type for a duration (#1881).
