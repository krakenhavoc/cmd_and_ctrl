**Statics that function from a graveyard** (#1221, [ADR 0071](decisions/0071-designations-that-switch-abilities-on.md)'s second 2026-09-22 addendum) — closes "Statics read from a non-battlefield zone" (count 3, four cards). `StaticAbility.Zones []ZoneKind` is `ActivatedAbilityShape.Zones`' and `TriggeredAbility.Zones`' sibling, with the same nil default and the same per-DECLARATION scope, read by ONE narrow gather beside the battlefield walk (`Game.declaredZoneStaticsLocked`, `game/static_zones.go`). The gather is `trigger_zones.go` (#925) one consumer over, down to the boot-time index: `staticZones.zones()` answers "does any registered card declare a static from a non-battlefield zone" — nil for almost every game, so the whole walk is one slice read — and `declares(oracleKey)` lets a walked graveyard skip the catalog lookup for every card that does not. The battlefield walk gains exactly one comparison per ability, which is what keeps a declared zone from ALSO applying there: a battlefield Anger is a 2/2 with its own printed haste and no anthem, and the card prints the keyword as a separate line for exactly that reason. `supportedStaticZones` is the GRAVEYARD alone and `effects.Register` refuses the rest at boot, because a zone the gather does not walk would be a declaration the engine silently ignored. Three details of the bound source are rules rather than choices: `Controller = Owner` (CR 108.4 — an Anger milled out of an opponent's library helps THEM), `live: false` (the flag exists only for CR 613.1f silencing, and nothing on the board can silence a card in a graveyard), and a timestamp taken from the source's last battlefield entry, which is unobservable for this whole family because every incarnation is a layer-6 GRANT and grants commute — a graveyard static that SET a characteristic would need a real zone-entry timestamp, and none is printed. The gather goes through `StaticAbilitiesForCard` rather than the raw hook, so the ADR 0071 designation gate is evaluated in the second place an object becomes statics exactly as in the first. **No new invalidation was needed**: #1117 widened the zone-keyed bump so any event crossing a graveyard boundary bumps `layerVersion`, arrivals and departures alike, and this is the first static that makes it observable — "the cached resolution survived the graveyard arrival" is now a one-line assertion instead of an argument. Shipped on Anger, Wonder, Brawn and Valor, all `full`, off one `incarnationAnthem(keyword, land)` constructor. Still open on this family: Yixlid Jailer is NOT this row (a battlefield static ABOUT graveyards — it wants the ability-suppression seam), "as long as this card is in your hand" statics have no card asking yet, and REPLACEMENT effects still have no zone field at all — mana abilities got theirs with #1228, below.
