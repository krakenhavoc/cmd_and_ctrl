**Whenever this Vehicle becomes crewed** (#5671, CR 702.122e; follows [ADR 0186](decisions/0186-crewing-and-saddling-who-paid-and-what-they-count-for.md)) — "Whenever [this Vehicle] becomes crewed" means "Whenever a crew ability of [this Vehicle] resolves", and the engine only had `EventCrewedVehicle`, which fires per creature while the cost is paid. `EventBecameCrewed` (`"became_crewed"`) is the resolution: `noteCrewAbilityResolvedLocked` runs after every activated ability's effect in `resolveTopAbilityLocked`, knows a crew ability by its catalog row (a cost with a crew component, read through the item's ability ref, so a copy of the ability and one restored from a snapshot count), and emits one event while the Vehicle is still on the battlefield as the object the ability came from. A countered crew ability, or one whose Vehicle left or came back as a new object (CR 400.7), emits nothing. `TurnTally.BecameCrewed` (additive in snapshot v9, `becameCrewed`) holds one `ObjectRef` per resolution, and the event's `Amount` is that object's count this turn, so "for the first time each turn" is `Amount == 1` whether or not the first trigger found a target. The vocabulary is `effects.WhenBecomesCrewed` and `effects.WhenBecomesCrewedFirstTimeEachTurn` (`becomes_crewed.go`). The event has no log line of its own: the crew ability's resolve line says it. **Cards:** Mobilizer Mech, Mindlink Mech (both Full).
