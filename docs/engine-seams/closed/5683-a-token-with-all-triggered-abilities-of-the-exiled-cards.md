**A token with all triggered abilities of the exiled cards, and exiling by name as a cost** (#5683, CR 111.3 / 707.2 / 608.2h / 613.1f / 601.2f / 601.2h) — The Book of Vile Darkness's "{T}, Exile The Book of Vile Darkness and artifacts you control named Eye of Vecna and Hand of Vecna: Create Vecna, a legendary 8/8 black Zombie God creature token with indestructible and all triggered abilities of the exiled cards" had neither half. ADR 0155's borrow lends activated abilities, with triggered ones beside them, as a layer-6 effect re-read on every pass; Vecna's clause is the creating effect defining the token's text (CR 111.3), which is fixed as the ability resolves and is the token's copiable values. So it is not a borrow and ADR 0155 is unchanged.
- **The token's text.** A token carries "all triggered abilities of <card>" as one part of its own text key, on `Card.GrantedAbilities` beside CR 707.9a's copy grants: `game.TriggersOfKey(<card's catalog key>)`. The catalog answers the derived key with that card's triggered rows and triggered mana abilities and nothing else (`game.TriggersOnlyDef`, built once per key by `effects.derivedTriggerDef`), so no activated or mana ability, static or cost modifier comes along. A Clone copies the part, an ability-removing effect with any timestamp removes it with the token's other abilities, and a card that later leaves exile changes nothing. `effects.CreateTokenWithTriggeredAbilitiesOf(ctx, template, lenders)` reads each lender where it is (`game.TriggeredTextOf`) and creates the token with the parts already on it, so a lent "when this enters" triggers for the token's arrival.
- **Row identity.** The rows are the lender's own, stamped with its catalog key, so a harvested trigger is keyed `own:<i>` under the lender's key, as a lent trigger is. It restores with no lender. No new effect key, mod kind or snapshot field: the parts are strings on a field the snapshot and the copy already carry, and a part naming a card this binary does not have resolves to nothing.
- **Triggered keywords.** A keyword the engine derives from the ability list joins the token's printed `Keywords` when it is a triggered ability and nothing else (prowess, evolve, exalted, melee, undying, persist, annihilator N, renown N). Decayed and modular are a triggered ability and a static one (CR 702.147a, 702.43a), so only the trigger is carried, as `game.KeywordTriggerKey(<token>)`.
- **The cost.** `game.AbilityCost.ExileNamed` (`effects.ExileYourPermanentsNamed(cardType, names...)`) exiles every permanent the activator controls with the card type and one of the names, the source left out. The set is read once as the cost is determined and nothing is announced; an empty set still pays; a permanent in it pays no other component (CR 118.3); a commander in it is asked CR 903.9a before anything is paid. The exiled permanents are recorded on `PaidCost.Exiled`. An exiled token is in the record and is not a card. No wire field: the row's label is the printed cost and the client sends nothing for it.
- **Merged definitions** now carry a part's `ManaTriggers`, which only a derived part has.

**Cards:** The Book of Vile Darkness, Eye of Vecna, Hand of Vecna — Full.
