**Decayed** (#2650, CR 702.147, CR 122.1b, [ADR 0101 amendment 2026-10-08](decisions/0101-keyword-counters.md)) — decayed is a canonical keyword now, the fifth whose trigger the engine derives from the ability list, after prowess, evolve, annihilator and exalted. `decayed` joins `canonicalKeywords` as a cumulative token (CR 113.2c), so a printed decayed, a layer-6 grant, a decayed counter and a token template's each work with no catalog entry. "This creature can't block" is folded into the restrictions after the layer pass (`foldDecayedLocked`, beside unleash's), so the block gate, the enumerator and the view read it through `Restricted`, and a creature that loses its abilities can block again. "When this creature attacks" watches the creature's own declaration (CR 508.3a, so a token put onto the battlefield attacking is never sacrificed), pins it by instance and object epoch, and resolves through the new keyed body `decayed/schedule`, which queues a CR 603.7 delayed trigger, `decayed/sacrifice`, for the beginning of the end of combat step. That trigger sacrifices the creature whether or not it is still attacking, and nothing for one that left and came back (CR 400.7). `CounterDecayed` joins `keywordCounterKinds`, which now holds all fifteen of CR 122.1b's kinds. The `"2/2 black Zombie with decayed"` token row is the template for the 18 other cards that make one. **Cards:** Falcon Abomination — Full.
