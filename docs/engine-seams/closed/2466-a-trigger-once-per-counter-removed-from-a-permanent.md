**A trigger once per counter removed from a permanent** (#2466, CR 603.2c, CR 122.2 and Protean Hydra's rulings) — "whenever a +1/+1 counter is removed from this creature" is one trigger per COUNTER, not per removal, and the removal side of #1841's placement twin. A removal is the same `EventCounterPlaced` with a lower post-change total, so `TriggeredAbility.PerCounterRemoved` (plain data: the counter kind) tells `harvestMatchLocked` to dispatch the ability once per counter the event took off, read off the log by `counterRemovedDeltaLocked` — `counterPlacedDeltaLocked` read the other way round. Any cause counts: a cost, an effect, the CR 704.5q cancel, and a prevention clause's own removal (Protean Hydra feeds its own trigger). A placement or another kind is zero occurrences, and counters that go away because the permanent left the battlefield are not removed at all (CR 122.2: the permanent no longer exists) — the engine clears them with the card and emits no event, so nothing fires. The constructor `WheneverACounterIsRemovedFromThis(kind, label, effect, zones...)` lives in `effects/counter_each.go`; the optional zones let a suspended card's "while it's exiled" ability watch from `ZoneExile` as suspend's own triggers do. Protean Hydra's end-step return is a delayed trigger pinned to the Hydra's object (`ObjectRef` with its epoch, CR 400.7), one per counter. **Cards:** Protean Hydra and Dinosaurs on a Spaceship, both Full (Magma Pummeler's reflexive "when one or more counters are removed this way" is its own, shipped, shape). **Still open:** the suspend-X cards with this ability (Benalish Commander, Roiling Horror, Detritivore, Fungal Behemoth, Aeon Chronicler) wait on a suspend cost with an X, and "whenever one or more counters are removed" (Chandra, Fire Artisan; Regenerations Restored; Cloudsculpt Armorer) is a batched reading that this per-counter shape is not.
