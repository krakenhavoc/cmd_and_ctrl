**Targets that must come from a single graveyard** (#1807, CR 601.2c / CR 608.2b / CR 115.7d-e, [ADR 0106 §5](decisions/0106-five-small-seams-from-the-s50-rechecks.md)) — "up to four target cards from a single graveyard" needed the opposite of #1559's set rule: every pick must SHARE a key rather than differ on one. `TargetSpec.Same *game.TargetSameness{Label, Key}` is that sibling, keyed on the card's owner (`game.TargetShareOwner`; a card is only ever in its owner's graveyard, CR 400.3) and built with `effects.FromASingleGraveyard()` or `UpToCardsFromASingleGraveyard`. The key is a closed enum, not a func, so the ADR 0041 closure ratchet gains no route and the snapshot is untouched: the clause is rebuilt from the catalog row on restore. The readers that judge `Different` each gained a "share" branch: the announce gate refuses a set with two keys (`those targets must come from a single graveyard`); the CR 608.2b re-check judges the surviving picks, with `setRuleConflictLocked`'s weaker reading; `fillableCountLocked` answers the largest key group, so an exact four (Pestilent Cauldron) is not offered unless one graveyard holds four; the one-slot retarget offer narrows to the graveyard the staying slots are in, while the gate judges only the final set, so moving every slot to another graveyard at once is legal (CR 115.7e); the enumerator builds sets inside one group; and the view ships `same: {label, keys}` beside `different`, which the client picker uses to grey every candidate outside the first pick's graveyard. **21 cards:** Digsite Conservator, Decompose, Scarab Feast, Rapid Decay, Shred Memory (with a new `Transmute` constructor, CR 702.53), Carrion Beetles, Rag Dealer, Famished Ghoul, Griffnaut Tracker, Arashin Sunshield, Gravegouger, Soul-Shackled Zombie, Ebony Charm, Rats' Feast, Serene Remembrance, Unlicensed Hearse, Waste Management, Kaya, Orzhov Usurper, Cease // Desist, Pestilent Cauldron // Restorative Burst, all `full`, and Push // Pull, whose Pull half returns its two creatures one after the other (`caveats`). **Still open**, on the row's Waiting list: Martyr of Bones, Qutrub Forayer, Feral Deathgorger // Dusk Sight and Spellweaver Helix, held for their other text.
