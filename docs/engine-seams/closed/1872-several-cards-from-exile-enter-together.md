**Several cards returned from exile enter together** (#1872, CR 603.6a / CR 101.4 / CR 111.8) — the exile half of #1867. The catalog's multi-card exile returns looped over the single-card exile door, so the first card was announced before the second moved: of two returned Soul Wardens only the first saw the other enter. `effects.ReturnFromExileTogether{Targets, Controller, Tapped, Then}` is `ReturnFromGraveyardTogether` for exile, over one shared body: it skips a card no longer in exile (CR 603.7c), a token (CR 111.8) or a nonpermanent, and tells `Then` the NEW object IDs (CR 400.7). The batch door now defaults "under its owner's control" to the CARD's owner, because exile is a shared zone owned by nobody and an exiled card's CR 614 window used to see no controller at all. The single-card exile door leaves a token in exile, so an immediate blink of a token returns nothing. **Converted:** Living Death (the last step is one entry for every player), the delayed blink's return (Waterbender's Restoration, The Eternal Wanderer, Charming Prince, Palace Jailer), the "until this leaves the battlefield" return (Hostage Taker, Ossification, Sheltered by Ghosts) and Oblivion Sower, which now also lets its controller choose any number of the lands as printed and refuses a face-down card (CR 406.3a), and goes `full`. Teval, the Balanced Scale and Blossoming Tortoise return their land with "tapped" on the entry event, closing the "enters untapped and is tapped a moment later" caveat. No snapshot field, effect key or closure route was added. Cosmic Intervention is deliberately unchanged: its ruling returns each card with its own delayed trigger, one at a time.
