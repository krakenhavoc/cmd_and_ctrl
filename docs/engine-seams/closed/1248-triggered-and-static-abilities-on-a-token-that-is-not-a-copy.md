**Triggered and static abilities on a token that is not a copy** (#1248, CR 111.1 / CR 111.7 / CR 707.2 / CR 603.10, [ADR 0083](decisions/0083-token-abilities.md)) — half the row's premise had already shipped and the row did not say so. **#521 gave a token a catalog identity** — `game.TokenKey`, `CatalogKey`'s fallback to `Card.TokenKey`, `PrintedValues.TokenKey` in the copiable values — so `TriggersForCard`, `StaticAbilitiesForCard` and `TriggersForKey` had been ABLE to answer for a token ever since; they answered with nothing because nothing could put anything in the slot. What was missing was the DECLARATION, and not by oversight: `token_catalog.go`'s builder returned a `game.Card`, and `game.Card` has no `Triggered` or `Static` field because a closure on the instance is exactly what #521 deleted (one live Treasure used to mean no restore point was written at all, ADR 0041). So the builder returns an `effects.tokenTemplate` instead: a slug, the printed characteristics, four ability slots side by side — `Mana`, `Activated`, `Triggered`, `Static`, written with the SAME `triggers_common.go` constructors and `game.StaticAbility` values printed cards use — and the printed text. Registered once at boot under `game.TokenKey(slug)` in the same `defs` map cards are filed in (never `registry`, so `All()` keeps counting cards). **No new `game.Card` field and no new dispatch path**: the instance still carries one string, so a board of ability-bearing tokens is still a restore point, and the harvest, the layer pass, the LTB harvest and the activation path all found the entry the moment it had something in it. ADR 0071's `ActiveWhen` gate and CR 613.1f ability removal ride along for free, because both live inside the shared accessor. **The registry is a LIST and the slug lives on the template**, which is not taste: a token template may name another token (Fable's Goblin Shaman makes a Treasure), and a slug-keyed map makes the package variable's initialiser reach back into itself — an initialization cycle Go refuses to compile. **Nine battlefield walks** stopped asking `c.OracleID == ""` and started asking whether the catalog KEY is empty (`block_rules.go`, `cast_timing.go`, `cast_permission.go` ×2, `land_drops.go`, `library_top.go`, `player_statics.go`, `effect_hooks.go`, `keywords.go`, plus `characteristic.go`'s printed-keyword read) — behaviour-neutral today, and the difference between a slot that answers for tokens and one that silently does not; an AST scan fails on the tenth. **The dies path** needed one field: `triggerIdentityLKI.TokenKey`, because restoring the CR 603.10 identity snapshot used to BLANK a dying token's key. CR 111.7 then CR 704.5d were already in the right order — the token reaches the graveyard, the harvest reads it there, the sweep runs last. **CR 707.2 needed nothing** and is asserted in both directions. **On the wire**: `CardDef.TokenText` → `game.TokenTextForCard` → `CardView.token_text` → `Card.svelte`'s name-fallback branch, required of every registered template at boot — a mana or activated ability reaches the player as a menu row, a TRIGGER has no control to hang text off, and a token has no printing to fetch oracle text from (ADR 0078 is still Proposed). **Cards:** Reef Worm (#459), Nesting Dragon (#397) and Mysidian Elder (#448) ship; Fable of the Mirror-Breaker (#343), Avatar Roku (#343), Beledros Witherbloom, Sedgemoor Witch and Cornered by Black Mages drop the caveat that named this row. Still open, each filed where it belongs: **Avatar Kuruk's Spirit token** ("can't block or be blocked by non-Spirit creatures" is a `game.BlockRule.Pair`, and `CardDef` has no `BlockRules` slot — ADR 0045's addendum PR 4, on the conditional-blocking row; its `OracleID` skip is fixed here, its Spec field is not); **double-faced tokens** (the transform row); **token art** (#1115 / ADR 0078); and Chocobo Racetrack (#394) and Gwaihir (#464), each now one template away and belonging to their own batch PRs.
