**The block declaration's completion point, and "attacks and isn't blocked"** (#1279, CR 509.1 / 509.2 / 509.3 / 117.3a, [ADR 0045 amendment 2026-09-24 (#1279)](decisions/0045-combat-restrictions.md) Decisions 38-39) — the gap #1227 inherited and declared on `UnblockedAttackerForEffect`: nothing marked a defender's CR 509.1 declaration DONE, so "has not declared yet" and "declared no blocks" were the same empty record. `Game.blocksDeclared` (per combat, carried by undo and the snapshot) is written by `completeBlockDeclarationLocked` at four points — the step's start for a defender with no legal block, `finish_blocks` (new, player-scoped, not priority-gated), the defender's own `pass_priority` in the step, and the step ending for anyone still pending — and completing announces: that defender's staged blocks lock in (the #830 lock-in now waits for its blocker's controller to finish) and then **`EventBlockersDeclared`** (Actor = the defender, Amount = blockers, 0 = "declared, none"). The last completion by pass or `finish_blocks` hands the ACTIVE player priority, so the attacker gets its post-block window instead of the defender's pass ending the step. Consumers moved onto it: `UnblockedAttackerForEffect` (ninjutsu waits for the defender), the #328 `block_decision_seats` signal and the enumerator's block moves (a declared defender is asked nothing more), the bot's block grace (reads the signal off the frame), and the client (a "Done blocking" / "No blocks" control on `block_pending_seats`). Wire: `block_pending_seats` / `blocks_declared_seats`, action `finish_blocks`. `effects.WhenAttacksAndIsNotBlocked` is the new trigger shape. **4 cards, all `full`:** Swamp Mosquito, Guiltfeeder, Abyssal Nightstalker, Eternal of Harsh Truths. **Still open, by choice:** a late block by hand after completion is still accepted (sandbox allowance), and the active player still receives priority on the step's entry before anyone has declared.
