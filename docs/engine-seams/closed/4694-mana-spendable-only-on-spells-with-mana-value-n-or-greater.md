**Mana spendable only on spells with mana value N or greater** (#4694, CR 106.6, CR 202.3, CR 202.3e) — "Spend this mana only to cast spells with mana value 4 or greater" (Ashling, Rimebound). `game.ManaRestrictManaValueAtLeast(n)` (`"mv:>=N"`, with `ManaRestrictManaValueAtMost` for "N or less") is a keyed tag about a spell: `ManaSpendContext` gained `ManaValue` and `ManaValueKnown`, set by `ManaSpendForCast` from the face being cast through `manaCostForValue` (a transformed spell's front face, a face-down spell's 0) and by `ManaSpendForCastParams` with {X} at the announced value, so the cast, the auto-tapper, the assist prompt, the `?x=` cost preview and the spend riders all read one number. `ManaSpendContext.WithX` recounts it, and the legal-move enumerator's affordable-X search does so per X and jumps to the X that first reaches a floating restriction's threshold (`NextManaValueX`), since the cost is no longer monotonic in X there. An activation, an unlock, an unknown purpose and an unreadable cost refuse the mana. The pool view keeps restricted mana in its own runs (`ManaPoolRun.restrictions`), and the bot's mana model counts such a run only for a cast its restriction admits, asked of the engine's matcher with the face and X being cast (`protocol.ManaRestrictionsAdmitCastAs`). The snapshot gains the spend context's `ManaValue` and `ManaValueKnown` keys (`pendingChoices[].assist.spend`), additive under v9. **Cards:** Ashling, Rekindled // Ashling, Rimebound (Full).
