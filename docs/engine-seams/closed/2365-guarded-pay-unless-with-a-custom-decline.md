**A guarded pay-unless with a custom decline** (#2365, CR 118.12 / CR 117.4, [ADR 0018 §6](decisions/0018-triggers-on-the-stack.md)) — "<do something to> target spell unless its controller pays {N}" where the consequence is not a counter. Only `CounterUnlessPaid` (#951) held the table while the guarded spell sat on the stack; Divert written with a plain `PayUnless` let the spell it targeted resolve before its controller answered. The halt was already derived from the guarded object (`PendingChoice.GuardsStackItem`, read live by the gate and by `internal/legal` through one predicate), so the fix is one field: `game.CounterUnlessPaidPrompt.OnDecline`. Nil is the printed counter and `CounterUnlessPaid` is unchanged; a non-nil effect runs on a decline (or an unaffordable "pay") under the same re-check, so it never runs for an object that has already left the stack. Card side: `effects.GuardedPayUnless{StackID, Cost, Question, OnDecline}`, whose decline is a `*Context` bound to the same stack item, so Divert's controller (not the payer) picks the new target through `ChangeTargets`. No wire, enumerator or protocol change. **1 card:** Divert (`full`). A sweep of the Oct 5 dump for "unless … pays" on a spell or ability found no other card whose consequence is not a counter; the uncatalogued counter-unless-pays cards (Temur Charm, Phantom Interference, Aether Spike) are different gaps and are not this shape.
