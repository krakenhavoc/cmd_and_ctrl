**Learn is an event a replacement can apply to** (#3525, CR 701.48a, 614.1a, 614.6, 616.1, 113.6b, [ADR 0191](decisions/0191-a-sideboard-is-the-outside-the-game-pool.md) amendment of 2026-10-23) — the last card of the sideboard seam, Retriever Phoenix: "As long as this card is in your graveyard, if you would learn, you may instead return this card to the battlefield." `effects.Learn` no longer queues its discard prompt directly: it calls `game.LearnForEffect`, which opens a CR 614 window on one `RepEventKeywordAction` (`KeywordActionLearn`, no count) and, if nothing replaced it, performs the learn through `game.LearnBody`, a hook the catalog installs for the unchanged discard, draw and Lesson pick. A replaced learn discards, draws and reveals nothing (CR 614.6). **The replacement shape** is `ReplacementEffect.KeywordInstead`, `DrawInstead`'s sibling for a keyword action: applying it cancels the action and records a registered body (`game.RegisterKeywordInstead`, the key an on-disk identity) that runs once the window has settled, may queue prompts, and calls `done` for the rest of the sentence. **Where it works from** is the graveyard gather dredge built (`FromGraveyard`), which now looks in the learning player's graveyard for a learn as well as the drawing player's for a draw. `effects.ReturnThisInsteadOfLearning(name)` is the declaration: an `Optional` yes/no, so declined the learn goes on as printed. Two Phoenixes are two "may"s asked in turn (the player takes one or none); a Phoenix beside any other replacement of a learn is the CR 616 ordering prompt; an opponent's learn is not offered it. The card returns under its owner's control, and its own enters trigger is "if you cast it", so a returned Phoenix does not learn. **Not widened:** the Phoenix's question is the generic CR 616 optional-replacement prompt, which carries the resume frame a dredge offer carries, so a table with it open is not a restore point (pinned by a test); the learn prompts that follow keep the closures they had. **Card** (Full): Retriever Phoenix. #3525 has nothing left waiting.
