**A conditional mode count** (#1590, CR 601.2b / CR 700.2, [ADR 0065 amendment 2026-09-27](decisions/0065-modal-and-multi-target-clauses.md)). "Choose one. If you control a commander as you cast this spell, you may choose both instead" is now `ModeSpec.RaisedMax` + `RaiseMaxIf`, declared with `ChooseOne(…).OrUpToIf(2, YouControlACommander)`. `RaiseMaxIf` is a registered key (`game.ModeCondition`), not a func, so the ADR 0041 closure ratchet gains no route. `(*Game).modeMaxLocked` (`ModeMaxForEffect` outside the package) is the one reader. It returns the raised bound while the named condition holds for the chooser and the printed `Max` otherwise; `Min` never moves. It is read once, when the choice is made: at announce for a spell, at activation for an activated ability, and as a trigger's `mode_pick` prompt is queued. The result feeds `validateModes`. Nothing re-asks it, so a commander that leaves in response does not take a chosen bullet back. The view stamps the same bound per caster on `modes.max`, so the picker offers "both" exactly when the gate accepts it; a bystander's public copy shows the printed bound. The bot enumerator widens its selections by the same accessor (#544). `Register` refuses a half-declared, non-raising or over-wide count. `YouControlACommander` registers the free-spell cycle's condition: a commander permanent the player controls, anybody's. **Cards:** Jeska's Will, Akroma's Will, Drown in Dreams, Will of the Mardu, Will of the Abzan and Flame of Anor (whose condition is `YouControlAWizard`) are now `full`. Will of the Sultai is new. The four whose bodies read `item.Targets[0]` now read each bullet's own target group through `OptionTargets`, in printed order. **Still open, and a different shape:** "choose both instead" driven by the caster's own optional cost (teamwork, kicker: HULK SMASH!, Inscription of Ruin, Depth Defiler, Pyrrhic Strike) and board conditions that FORCE the higher count (Prophetic Titan). Both need `Min` to move and, for the first, a bound that reads the announced optional costs.
