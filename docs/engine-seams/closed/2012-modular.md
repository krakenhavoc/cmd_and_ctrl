**Modular** (#2012, CR 702.43) — modular is a canonical keyword now, NUMBERED like annihilator: the tokens are `"modular N"` (`CanonicalModularToken`; a bare "modular" is refused, and the deck importer reads the number off the keyword line), and it is cumulative (CR 702.43b). Its static half is an entry replacement gathered like riot's: the CR 614.12 entry look-ahead counts the instances the permanent would have on the battlefield, and the gather adds one mandatory self-replacement per instance that puts N +1/+1 counters on the entry event, so every entry path (a cast, a reanimation, a flicker) gets them and Hardened Scales sees them. A modular instance only adds counters, so it is applied alone after the CR 616.1b control tier rather than ordered. Its triggered half is a dies keyword like undying: `harvestLTB` derives one trigger per instance from the last-known ability list (CR 603.10a), a "you may" (CR 603.5) that targets an artifact creature and, through the new keyed body `modular/move-counters`, puts on it one +1/+1 counter per +1/+1 counter the permanent last had, re-checking the target (CR 608.2b). **Cards:** Arcbound Ravager — Full. The keyword-only modular creatures (Arcbound Worker, Arcbound Slasher with riot, and others) need no card file. **Not built:** Modular—Sunburst stays Arcbound Wanderer's own card file.
