**Conditional exile play permissions** (#3192, [ADR 0066 second amendment 2026-10-13](decisions/0066-granted-cast-and-play-permissions.md), CR 611.2b / 118.9 / 400.7 / 508.1) — a granted permission can now be live only while a condition holds, and stay dormant (granted, the card still exiled) on the turns it does not: "during any turn you attacked with a token, you may play that card", "you may play it if you control a Kavu", "as long as you attacked this turn". `game.CastPermission.Condition` is a registered key plus plain parameters (`game.PermissionCondition`, `game.RegisterPermissionCondition`), so the permission stays data, survives Clone, undo and a snapshot, and the closure-field ratchet does not move; a snapshot naming a key this binary never registered is refused at restore, and an unknown key at run time fails closed. It is evaluated in `CastPermissionActiveForEffect`, the one liveness test the cast path, the view, the legal-move enumerator, the bot and the library-top look already share, so none of them can disagree. Built-in conditions: attacked with a token / a commander / a creature type / N or more different creatures / one named object / anything this turn, controls a creature type, and put a lore counter on a named Saga this turn. The attack ones read per-turn tallies recorded as each attacker is declared (`PlayerTurnTally.TokensAttacked`, `CommandersAttacked`, `TurnTally.AttackedSubtypes`, with the existing `Attacks` list for objects and distinct counts; `TurnTally.LoreCounterPut`), so a token that died in combat still counts, and a tally clears at the turn boundary. A spell-type gate ("if it's a creature spell") is the permission's `Filter`, which `CoversCard` now applies to a named-cards permission too. "For as long as you control <source>" needed nothing: it is the source-bound `ForAsLongAs` duration the permission already carried. Wire: `exile_play.condition` (the printed clause) and `exile_play.condition_unmet`, so the client withholds the button on a dormant grant. Snapshot: additive `castPermissions[].condition`, `turnTally.attackedSubtypes`, `turnTally.loreCounterPut`, `turnTally.players[].tokensAttacked` / `commandersAttacked`. **10 cards:** Neyali, Suns' Vanguard (now `full`), Boros Strike-Captain, Goblin Researcher, Robber of the Rich, Pick Up the Pace, Neriv, Crackling Vanguard, Possibility Technician, Lightning, Security Sergeant, Victor Mancha, Runaway and Nivix, Aerie of the Firemind (all `full`).
