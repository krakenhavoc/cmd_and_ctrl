**Combat reassignment after blockers are declared** (#6193, CR 509.1h, 509.3) — blocks an effect changes once the declaration is over (game/combat_reassign.go). Every block now leaves a record, `TurnTally.CombatBlocks` (blocker, attacker and combat phase), whether it came from the declaration, a creature put onto the battlefield blocking, or an effect. That record answers "hadn't become blocked by another creature this combat" after the other blocker has left combat. `BecomeUnblockedForEffect` takes an attacker out of the blocked record (CR 509.1h: "an effect says that it becomes … unblocked"). `RemoveBlockerUnblockingForEffect` is the shared text of Balduvian Warlord, Ydwen Efreet and False Orders. `BlockAttackersForEffect` makes an existing creature block chosen attackers without a declaration. It uses the declaration's pair legality and the CR 506.3e defending-player rule (`CanBlockByEffectForEffect`), and emits CR 509.3's events: an `EventBlock` per new pair, with "whenever ~ blocks" only for a creature that wasn't blocking, and an `EventBecomesBlocked` only for an attacker that was unblocked, so a "becomes blocked" trigger never fires twice (#830). `SwapBlockersForEffect` is Sorrow's Path and `SwitchBlockedAttackersForEffect` is General Jarkeld. **Cards:** Balduvian Warlord, Ydwen Efreet, False Orders, Sorrow's Path and General Jarkeld, each built by its own OLD batch (b561, b892, b898, b863, b832).
