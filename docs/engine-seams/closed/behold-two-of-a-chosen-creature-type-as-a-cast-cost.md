**Behold two of a chosen creature type as a cast cost** (#5406; CR 601.2b, 601.2f, 701.4a) — `effects.OptionalBehold` fixed the creature type on the card and took one card, so Celestial Reunion's "you may choose a creature type and behold two creatures of that type" had no shape. `game.RevealCost` grows `Count` (behold N), `ChosenType` (the clause prints no type; the caster names one as they announce the cost) and `Creature` (creature cards and creatures only, never Kindred, per the card's ruling). `cast_spell` takes the type as `behold_type` (CastSpellParams.BeholdType) beside the objects on `reveal_ids`: announce checks it is a CR 205.3m creature type and then validates exactly N distinct objects of that type through the alternative cost's behold N rule (`validateBeholdPaymentLocked`), and refuses a type sent for a cast that chose none. Hand cards are revealed in one reveal, permanents are chosen. The type lands on the stack item as `PaidCost.BeholdType` and the resolution reads it through `ctx.BeheldType()`. `Game.BeholdTypeOptionsForEffect` is the one walk the view (`optional_costs[i].behold_count` / `behold_types`, `reveal_options` min and max N), the enumerator (one payment: the type with the most objects, permanents first) and the validator share (#544). `effects.OptionalBeholdChosenType(n)` builds the cost, and `checkOptionalBehold` refuses any other shape. Celestial Reunion's "put that card onto the battlefield instead" is `SearchLibrary.OntoBattlefieldIfSubtype`, plain data on the search spec, so an open search prompt is still a restore point. The same PR ships Dawnhand Dissident, whose cast permission charges Quilled Greatwurm's counter removal through the new `CastPermission.RemoveCountersInAddition`.
