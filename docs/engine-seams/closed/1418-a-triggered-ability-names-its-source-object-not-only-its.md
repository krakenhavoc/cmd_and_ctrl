**A triggered ability names its source OBJECT, not only its card** (#1418, CR 400.7 / 113.7a / 603.7d / 603.12, [ADR 0018 amendment 2026-09-24](decisions/0018-triggers-on-the-stack.md) Decisions 14-16). A triggered item carried `SourceCardID` and nothing else about its source. `StackItem.SourceEpoch` was stamped by the two activation paths only. So "this" in a trigger whose event was not about its source (an upkeep, draw-step or cast trigger) read the object the card was NOW, and a source flickered in response was judged as the new object. **`StackItem.SourceObject ObjectRef`** is now stamped on every ability item where it is made: the trigger dispatch after `Build` (`stampTriggerSource`, from the dispatch's value copy of the source, or from the event's own snapshot when the event is about the source, so a dies trigger names the permanent that died), `queueHarvestedTriggerLocked` for any item without one, both activation paths (read before costs, so a source sacrificed to its own ability is still named), delayed triggers (`DelayedTrigger.SourceObject`, inherited from the resolving creator, CR 603.7d), reflexive triggers (the parent's, CR 603.12) and ability copies. Clone and the snapshot carry it (`carried` in `snapshot_drift_test.go`). `Game.SourceObjectForEffect` is the read, and `effects.Context.SourceRef()` / `SourcePermanent()` are the card-side spellings. `SourcePermanent()` is `PermanentForEffect` on that ref: live while the object is there, its record once it has gone. `AbilitySourceGoneForEffect` now asks the object of every stamped item, triggers included. An unstamped item from an older snapshot keeps its old rule. Proof cards: **Mana Vault** ships `full` (its last caveat was this issue); **Batterskull** (living weapon), **Hero's Blade** and **Uthros Research Craft** no longer attach or counter a new object that their card became while the trigger waited. Still open, stated in the amendment: a spell item carries no source object (nothing asks yet). Trackers [#881](https://github.com/krakenhavoc/cmd_and_ctrl/issues/881).
