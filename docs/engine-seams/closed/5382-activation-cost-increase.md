**An activation cost increase, including abilities with no mana cost** (#5382, CR 602.2b / 601.2f / 605.3 / 606.4 / 118.7a) — the CR 601.2f pass already priced activations for board modifiers (`CostModifier.Activations`, #1184), but `AbilityManaCostAtXForEffect` and `ManaAbilityManaCostForEffect` returned early for a cost with no mana component, and the activation's payment gate, the enumerator, the view's `charged_mana_cost` and the auto-tapper all tested the printed string. So "activated abilities of sources with the chosen name cost {2} more to activate" (Skyseer's Chariot) could not reach a {T}-only ability, a mana ability, crew or a loyalty ability.
- **The pricers.** For a cost that prints no mana, both pricers now run the pass exactly when an activation-scoped `CostIncrease` applies (`Game.activationTaxApplicableLocked`: board, eminence, planar and the ability's own clauses, judged by `AppliesTo`); with none, the printed empty cost comes back unchanged and nothing else runs, so every untaxed {T}-only ability prices as before. Increases sum, one {N} per applying modifier. `AbilityPriceReadsTargetsForEffect` counts only increases for such a cost.
- **One question for every reader.** `Game.AbilityChargesManaForEffect` and `Game.ManaAbilityChargesManaForEffect` ("does this activation owe any mana") replace the `Cost.Mana != ""` / `ManaCost != ""` tests in `ActivateCatalogAbility` (so crew and loyalty abilities pay it too), `ActivateManaAbility` (the tax is paid before the mana is made, so a taxed Sol Ring cannot fund its own {2}), the legal enumerator's activated and mana moves, the view's activated and mana rows, the ordinary and costed auto-tap planners (a taxed mana source is a costed source, never a free one) and `LandManaOptionsForEffect`. The bot seat reads the enumerator's gate and the row's `charged_mana_cost`.
- **Card side.** `effects.ActivationCostsMore(n, label, preds...)` is the increase twin of `ActivationCostsLess`; `effects.OfASourceWithTheChosenNonlandName()` matches the ability's source against the modifier permanent's `Card.ChosenName` through a non-land face, as Phyrexian Revoker does. The chosen name is existing per-instance state, already in the snapshot: no schema change.
- **Client.** The ability menus show the charged chip on a row that prints no mana when the server stamps one, with the tooltip "printed cost has no mana".
- **Not covered:** the sandbox `ActivateLoyalty` verb for an uncatalogued walker pays no mana by design, so it does not charge the tax.
- **Cards:** Skyseer's Chariot (Full).
