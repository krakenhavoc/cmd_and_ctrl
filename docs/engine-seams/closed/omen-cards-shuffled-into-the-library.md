**Omen cards, shuffled into the library** (#5175) — Scryfall lays an omen card (CR 720) out as an `adventure`, so its Omen half was castable already and resolved down the Adventure path: exiled, with its creature castable from exile, which is stronger than printed. `castAsOmen` (`game/omen.go`) reads the Omen spell type off the materialised face, `castAsAdventure` refuses it, and the Omen's resolution exit (`resolution_exits.go`, CR 720.3d) routes the card to its owner's library and shuffles that library in a keyed tail (`engine/omen-shuffled`), even when the card went elsewhere (CR 701.24c). It competes with a granted buyback or rebound under CR 616.1 like any other exit; a countered or fizzled Omen goes to the graveyard. The engine, the view and the bot enumerator still offer both halves through the one face gate, `CastableFaces`. **Cards:** Bloomvine Regent // Claim Territory, Dirgur Island Dragon // Skimming Strike, Disruptive Stormbrood // Petty Revenge, Feral Deathgorger // Dusk Sight, Marang River Regent // Coil and Catch, Purging Stormbrood // Absorb Essence, Riling Dawnbreaker // Signaling Roar, Runescale Stormbrood // Chilling Screech, Sagu Wildling // Roost Seek, Scavenger Regent // Exude Toxin, Stormshriek Feral // Flush Out, Twinmaw Stormbrood // Charring Bite, Whirlwing Stormbrood // Dynamic Soar (all Full).
