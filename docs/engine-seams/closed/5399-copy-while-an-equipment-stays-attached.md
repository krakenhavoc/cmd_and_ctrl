**A copy effect for as long as an Equipment stays attached** (#5399, CR 607.2a, 610.3, 611.2b, 613.2a, 701.3b, 707.2) — Assimilation Aegis's "whenever this Equipment becomes attached to a creature, for as long as this Equipment remains attached to it, that creature becomes a copy of a creature card exiled with this Equipment" had three missing pieces. **The duration:** `effects.BecomeCopy` takes `CopyWhileSourceAttached`, the engine's existing `WhileSourceAttachedToPinned` (Dinosaur Headdress's) on a resolving ability's copy: one target, the ability's source still the same object attached to it, and never started when it isn't (CR 611.2b); moving the Equipment ends it for good. **The pick:** `effects.BecomeCopyOfExiledWith` lists CR 607.2a's linked set (`Game.ExiledWithRowForEffect` over the exiling row), filtered by the card's printed types in exile; one candidate is copied, two or more are a keyed choose_cards pick (`choose-cards/become-copy-of-exiled-with`, carrying the target, its object epoch and the duration as data, so a table waiting on it is a restore point), none copies nothing. The copy holds the card's printed copiable values (CR 707.2) as a layer-1 duration copy with its own timestamp. **The link and the trigger:** `ExileUntil.Linked` stamps the "exiled with" link on an "exile … until this leaves the battlefield" card (CR 610.3), and `effects.ThisBecameAttachedToACreature` is "whenever this becomes attached to a creature" off `EventAttach`, skipping a re-attach to the same creature (CR 701.3b). No snapshot, protocol or client change. **Cards now Full:** Assimilation Aegis. **Still open:** an attach trigger whose Equipment moved away and back to the same creature before it resolved still applies its copy, where strictly that duration had already ended.
