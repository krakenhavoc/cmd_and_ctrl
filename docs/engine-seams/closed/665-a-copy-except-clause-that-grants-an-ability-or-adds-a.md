**A copy "except" clause that grants an ability or adds a subtype** (#665, [ADR 0043 amendment](decisions/0043-copy-effects.md)): `PrintedValues` gains `AddSubtype` / `RemoveSubtype` / `HasSubtype` (CR 707.9b) and `GrantAbility(name)` (CR 707.9a). A grant is stored as a NAME in the copiable values — `PrintedValues.GrantedAbilities`, materialised onto `Card.GrantedAbilities` — so a Clone copying a Phantasmal Image inherits the Illusion type and the sacrifice trigger, and a snapshot carries both. The abilities themselves are static catalog data on the card that grants them (`effects.Spec.Grants`, `AbilityGrant{Key, Triggered, Static, Activated}`), filed under `game.GrantKey(Key)` in the same `defs` map cards use, the way an emblem is. **One lookup seam:** `CatalogKey` returns a composite `"<oracle_id>|grant:<name>"` and `catalogDef` merges the card's definition with each grant's (`game/copy_grants.go`), so the trigger harvester, the layer pass, `ActivateCatalogAbility`, the replacement gather and the view all see a granted ability with no reader of their own; ability removal (`CatalogAbilityKey`) and face-down silence (CR 708.2a) both still win, because both answer before it. `game.BaseCatalogKey` is for the two sites that read a key as an identity. **Cards:** Phantasmal Image (new, with the declined-0/0 caveat Clone also carries) and Sakashima the Impostor, which drops its caveat and is now Full. Still open: a copy effect with a DURATION (Mirage Mirror, Cytoshape); granted MANA abilities have no slot; a granted ability's text is not on the wire. Estrid's Invocation (#387) and Machine God's Effigy (#389) are unblocked by this and still need their own files.
