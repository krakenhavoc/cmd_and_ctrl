**Tiered (CR 702.183)** (#3777, [ADR 0065 amendment 2026-10-15](decisions/0065-modal-and-multi-target-clauses.md)) — "Tiered (Choose one additional cost.)" is Spree's per-bullet cost (`game.ModeOption.Cost`, CR 702.172a) with exactly one bullet chosen. `effects.Tiered(options...)` is the mode spec with `Min: 1, Max: 1` and the `effects.TieredPrompt` prompt, each bullet a `SpreeMode` / `SpreeModeDoing`; no engine change. The cast gate refuses no bullet and two bullets, the cast price adds the chosen bullet's cost (a "{0}" bullet adds nothing), `internal/legal` offers one cast per affordable tier and never two, and the client's mode picker already shows each bullet's cost. The roadmap has a `tiered` mechanic row. **Cards:** Cloud's Limit Break (Blade Beam's "different controllers" is the `EachDifferentController` set rule), Thunder Magic, Fire Magic, Tifa's Limit Break (Final Heaven's "triple" is +2X/+2Y read as it resolves) and Restoration Magic — all Full. **Not written in this slice:** Ice Magic and Vincent's Limit Break.
