**Returning the permanent itself to hand as a cost** (#2028, CR 602.2b / 601.2h) — a cost could return "a permanent you control" matching a filter, but a filter can't name the ability's own source, so "Return this enchantment to its owner's hand" couldn't be told from another copy of the same card. `game.AbilityCost.ReturnSelf` (`effects.ReturnThis`) is the sibling of `SacrificeSelf` and `ExileSelf`: paid at announce with the other returns, to the permanent's OWNER's hand, with the stack item's source object stamped before the payment so the effect reads the returned permanent's last-known information (CR 400.7, 608.2h). A commander that returns itself is asked about the command zone before anything is paid (CR 903.9b, ADR 0115). It is battlefield only, and the source can't also pay another component of the same activation. The wire carries `return_self`; the legal enumerator and the auto-tapper keep the source out of the other picks; the heuristic charges half the permanent (all of a token) for giving it up. **Cards:** Gossamer Chains, Shigeki, Jukai Visionary, Attunement, Broken Fall, Molting Skin, Steelshaper Apprentice and Rootha, Mercurial Artist (all `full`). **Still open:** the same cost on a MANA ability (Grinning Ignus), and Chthonian Nightmare, which also pays energy (#1995).
