**Search to exile, a non-owner searcher, and a stack-exit sibling for "return to hand"** (#1230, CR 614 / CR 903.9 / CR 701.6) — closes the **Search with an exile destination** row and the **Counter-to-hand / counter-to-zone effect surface** row whole, and half of the **Search / library-interaction primitives** row. Three small parameters, no new pipeline. (1) `game.searchDestZoneLocked` gained a `ZoneExile` case, so a search's take routes through the EXISTING `searchRoute` / `routeCardToZoneLocked` exit exactly as a hand or graveyard destination does — that exit already resolved `ZoneExile`, only the pre-check didn't. `SearchLibrarySpec.Unbounded` is the "any number of … cards" spelling `Limit`'s zero value couldn't carry (`<= 0` already meant "default to 1"), and `SearchLibrarySpec.FaceDown` rides a `FaceDownKind` through the same route in case a future card says "exile it face down" (unused today). **Ugin, Eye of the Storms**'s −11 is the proof, `full` now. (2) `SearchLibrarySpec.LibraryOwner` names the seat whose library is actually scanned, when that differs from `Player` (the chooser) — Bribery's "search TARGET OPPONENT's library and put that card onto the battlefield under YOUR control" needed exactly one new field, because every other reader of the spec (chooser, entering controller, stamped Actor) already meant `Player` and was already right for a control-changing entry. **Bribery** ships `full`; **Aven Mindcensor**, the row's other card, stays open below — its "search the top four instead" is a static REPLACEMENT over every search a restricted player makes, board-wide, which is a new mechanism (a search-replacement hook) rather than a parameter any one search call can carry. (3) `counterSpellLocked`'s body is now `exitSpellFromStackLocked(spellID, dst, fallback, countered)`, shared by the counter (`countered: true`, `CounterTargetToZoneForEffect` is the new card-effect wrapper exposing the destination the private function always had) and by the new `ReturnSpellToHandForEffect` (`countered: false`, fallback `ZoneHand`) — CR 701.6 never applies to the second one, so a spell printed "can't be countered" is still bounced and no "whenever a spell is countered" trigger fires, while both share the S29 flashback override and the CR 614 / CR 903.9 window through `routeCardToZoneLocked`. **Reprieve** and **Narset's Reversal** (the row's two cards — read closely, neither says "counter") are the proof for the bounce half; **Devious Cover-Up**'s exile clause, caveated since it shipped with a note naming this exact gap, is the proof for the destination-parameter half, and is `full` now too.
