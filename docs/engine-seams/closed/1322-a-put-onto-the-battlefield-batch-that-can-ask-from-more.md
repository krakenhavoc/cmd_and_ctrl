**A "put onto the battlefield" batch that can ask, from more than one zone, and an exile return that reports what arrived** (#1322, #1324, #1327, CR 614.12a / 614.12b / 603.6a / 400.7, [ADR 0061 amendment 2026-09-23](decisions/0061-token-creation-and-discard-are-replaceable-events.md)) — three entry-path gaps the *Aang is so flashy* deck triage (#1306) filed together because they share one body. **The batch is resumable** (`game/entry_batch.go`): `putOntoBattlefieldFromZoneLocked` was the last effect-side entry built without `entryResumable`, because its only possible resume landed one card after its siblings had been announced. It now walks its cards' CR 614 windows one at a time and carries itself across a question on `entryTail.batch`; the resume hands each settled event back to the batch instead of landing it, and the batch lands, announces and runs hooks for every card once the last answer is in. CR 614.12b follows from the order (a payment made for the first card shrinks what the second can pay). **One entry from two zones**: `Game.PutOntoBattlefieldTogetherThenForEffect([]BatchEntry{{CardID, From}}, opts, then)` with `From` hand, library or exile (an exiled card returns as a new object). **The exile return has a continuation**: `ReturnFromExileToBattlefieldThenForEffect` / `effects.ReturnFromExile.Then`, told the new object's ID once the entry is complete. The finisher `executeEntryToBattlefieldLocked` is split into `landEntryLocked` / `announceEntryLocked` / `runEntryHooksLocked` so the batch runs the same landing the single entry does — which also gives a Clone put by Genesis Wave its copy choice. Two fixes the batch exposed: a face-down entry (manifest) no longer applies the entering card's own replacements (CR 708.2a), and the copy prompt's resume goes through the shared finisher so a cancel after it cannot strand a batch. **Cards:** Sword of Hearth and Home and Phelia, Exuberant Shepherd registered complete; every shockland (10), pay-life / enters-tapped / Pathway MDFC land back (60) and reveal-land (10) loses its "a spell PUTS it onto the battlefield" caveat and is complete. Still unresumable: the sandbox `move_card` verb only.
