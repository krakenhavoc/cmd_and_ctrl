**State triggers about each of several objects** (#1858, CR 603.8 / 400.7, [ADR 0107 §1](decisions/0107-state-triggers-rebound-disturb-and-damage-prevention.md)) — Bomb Squad's "Whenever a creature has four or more fuse counters on it, remove all fuse counters from it and destroy it". The state is a fact about one creature, so the ability triggers once for each creature in it. A row whose `State` key names a `game.StateEachCondition` (`RegisterStateEachCondition`, in the same package-level registry and key namespace as `RegisterStateCondition`) is asked once per battlefield permanent. Each instance it queues names that permanent as its trigger context's `Object` (ID and epoch) with no event, so `TriggerContext.Fired` stays false and the effect reads the creature through `ctx.TriggeringPermanent()`, by last-known information once it has gone (CR 608.2h). The CR 603.8 latch reads the same `Object`, on the trigger queue, the stack, the resolving slot and every open announcement prompt: an instance about one creature does not latch the ability for another, a creature that left and came back is a new object (CR 400.7), and two Bomb Squads each trigger for one creature, as the card's ruling says. The latch stays derived: the object is already snapshot data on every queued and stacked item, a new v7 corpus board (`state_each_trigger_on_stack`) holds one, and no closure route, ceiling or shape key changed. Helpers: `effects.WhenStateEach` and `WheneverACreatureHasAtLeast`. **Cards** (1, Full): Bomb Squad. The seam has no cards left waiting.
