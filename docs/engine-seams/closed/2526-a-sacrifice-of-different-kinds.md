**A sacrifice of different kinds** (#2526, [ADR 0020 amendment 2026-10-07](decisions/0020-activated-abilities.md)) — the COST half of the `set-level-sacrifice-cost` row, narrowed to "one permanent of each printed kind": Jarad, Golgari Lich Lord's "Sacrifice a Swamp and a Forest: Return this card from your graveyard to your hand". A sacrifice clause is one predicate with a count, judged one permanent at a time, so "a Swamp or a Forest" passed two Swamps. `game.TargetSpec.EachOf` carries the printed kinds as DATA (`game.SacrificeKind`: a subtype or a card type, so it adds no route from Game to a func, ADR 0041) beside a union predicate (`effects.SacrificeEach` / `SacrificeSubtype` / `SacrificeCardType` build both): the picks must fill every part one-to-one, so two Swamps are refused and a Swamp Forest fills one part but not both. One validator (`validateSacrificeCostLocked` → `sacrificeSetSatisfiedLocked`) answers it for an ability, a mana ability and a cast's additional cost alike. `legal.sacrificePayments` takes one payment from `game.SacrificeSetPaymentForEffect` instead of "the first N" (a backtracking search that tries the permanent fitting FEWEST parts first, so a dual land stays on the board while basics will do), and `LegalTargetsView.each_of` ships each part's candidates so `SacrificeCostModal` holds confirm until the parts are filled and "Choose for me" picks a set that fills them. `effects.Register` refuses a set rule whose count is not its entry count. **Jarad, Golgari Lich Lord** ships `full`. What stays open on the row is a rule over an ATTRIBUTE of the picks ("three artifact tokens with different names"), which Transmutation Font still waits on.
