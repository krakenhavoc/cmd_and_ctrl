**Retarget to a fixed object** (#1743, CR 115.7b / CR 400.7, [ADR 0019 amendment 2026-10-01](decisions/0019-structured-targeting.md)) — "change a target of target spell or ability TO THIS CREATURE", the shape the `Stack-item retarget` and `Targeting an activated or triggered ability on the stack` entries both left open under Spellskite's name. It is one field on the existing offer, not a second retarget: `game.RetargetOffer.To` (card side `effects.ChangeTargets.To` / `ToSource`) pins the destination, and a slot is eligible only when the item's list with that one slot replaced by the destination passes `retargetCheckLocked` — the gate a free "change the target" answer already passes — so the slot's clause and zones, hexproof / shroud / protection judged for the ITEM's controller, the same-clause duplicate rule, `Distinct` and the #1559 set rules all apply with no line of their own, which is every one of Spellskite's 2020-08-07 rulings. No eligible slot changes nothing and asks nobody. `ToSource` refuses a source that has left the battlefield, including one that came back as a new object with the same instance ID (CR 400.7, #1418's `SourcePermanent`). The only question the variant asks is WHICH slot ("you choose which one target you're changing … as Spellskite's ability resolves"): one eligible object under a mandatory change is changed with no prompt; otherwise a `retarget` prompt whose options are the CURRENT targets that could change, carrying the new `PendingChoice.RetargetTo`, which `ResolveRetarget` routes to `resolvePinnedRetargetLocked`. Same prompt kind, same departure row, same wire, same `internal/legal` case; `RetargetTo` is carried by the snapshot (additive in v7). Two instances of "target" naming one object are one option on the board and the earlier slot changes — weaker than printed, declared as a caveat. **3 cards:** Spellskite (`{U/P}`, payable with 2 life through #917) and Mizzium Meddler are new with that caveat; Hydroelectric Specimen's enters trigger is built and the card is `full`. **Still open:** Captured by the Consulate ("to enchanted creature if able") and Ricochet ("to the player with the lowest result") need no new retarget machinery and wait for a batch; Muck Drubb's "target spell that targets only a single creature" is a predicate over what a slot names, the gap #1815 records for Chef's Kiss.
