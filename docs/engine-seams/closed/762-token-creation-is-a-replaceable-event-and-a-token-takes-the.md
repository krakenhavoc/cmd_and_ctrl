**Token creation is a replaceable event, and a token takes the entry pipeline** (#762, [ADR 0061](decisions/0061-token-creation-and-discard-are-replaceable-events.md)): `RepEventCreateTokens` is opened once per creation INSTRUCTION (CR 701.7b) and carries token GROUPS — template, count and entry clause per kind — so a doubler multiplies the counts (`ev.MultiplyTokens`) and Academy Manufactor rewrites the kind set (`ev.ReplaceTokenKindsWhere`). Two copies of one doubler are ×4 with no prompt (#792's identical window); two DIFFERENT effects are a CR 616 ordering prompt the creation's controller answers, and either half can pause — the rest of the batch rides the entry's continuation, and `CreateTokensThenForEffect` is how a caller keeps its "then". Every token the window settles on then enters through `enterBattlefieldThroughPipelineLocked`, #478's one effect-side entry primitive, finished by the same `executeEntryToBattlefieldLocked` a fetched, reanimated or blinked permanent takes — so enters-tapped, enters-with-counters and `fireETBHookLocked` all reach a token, a paused token entry resumes through that frame, and the rest of the batch rides its `entryTail`. Shipped on 4 new cards — **Parallel Lives**, **Anointed Procession**, **Academy Manufactor** and **Mondrak, Glory Dominus** (caveat: its Phyrexian-mana ability) — and cleared **9 catalog caveats**: Doubling Season and Primal Vigor's token halves, the enters-tapped gap on Urabrask the Hidden, Manglehorn and Kinjalli's Sunwing, the enters-with-counters gap on Renata, Called to the Hunt, Dragonstorm Globe and Arwen, Weaver of Hope, and All Will Be One's token clause. Still open and named in #762: a choice INSIDE a creation replacement (Jinnie Fay, Esix, Mirrormind Crown, Moonlit Meditation) and "the first time you would create tokens each turn". CR 111.13's copy-becomes-a-token shipped in #666 (see above) and is a fifth caller of this creation path.
