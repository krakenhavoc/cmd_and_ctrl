**A spell reads what its sacrifice cost took** (#2072, CR 400.7j / 608.2h / 707.10, [ADR 0113](decisions/0113-small-seams-for-the-s58-deck-requests.md) §1) — `PaidCost.SacrificedObjects` names every permanent a sacrifice component took, as the battlefield object it was (instance ID and epoch), in the order named; it is written beside `PaidCost.Sacrificed` at all three payment sites (a spell's additional cost, an activated ability, a mana ability), read before the payment moves the permanents. `Context.SacrificedPermanents()` reads each one through `Game.PermanentForEffect`, so an effect sees the permanent as it last existed on the battlefield, anthem bonuses and counters included; `SacrificedPower()` floors the first one's power at zero and `SacrificedTotalPower()` sums them and floors the total (CR 107.1b). A CR 707.10 spell copy now carries both the list and the count, so a copied Tend the Pests makes the original's Pests and a copied Vicious Betrayal, Devouring Greed or Devouring Rage no longer reads zero; an ability copy carries the list beside the count it already carried. `b17PermanentSacrificedToPay` (Jarad, Greater Good, Birthing Pod and the rest) reads the record, keeping its event-log scan only for a restore point written before the field. Additive within schema v7 (`stackMeta[].paid.sacrificedObjects`, corpus board `sacrifice_cost_objects`). **Cards:** Fling, Kazuul's Fury, Momentous Fall, Tend the Pests and Corpse Cobble (Full). **Moved to another row:** Extus, Oriq Overlord, whose magecraft also fires on copied spells.
