**A target clause widened by an announced optional cost** (#1716, CR 601.2b / 601.2c / 608.2b, [ADR 0089 amendment 2026-09-28](decisions/0089-gift.md)) — "if this spell was kicked / cast using teamwork, instead … target …". The issue framed it as `TargetSpec.CardOK` being unable to read `item.Paid.OptionalCosts`; it does not need to. ADR 0089 §3's `AdditionalCost.Targets` already REPLACES the whole clause when that optional cost is paid, and `game.TargetSpecUnderOptionalCosts` is the one "which clause applies to this cast" answer: at announce (the result is stored on the stack item and is what the live CR 608.2b re-check reads), in `castTargetSpecForItem` for restore and copies (from `StackItem.Paid.OptionalCosts`), in the enumerator, and now in the view too — `viewOfOptionalCosts` asks it per offer instead of reading `oc.Targets` directly. Two changes made it reachable beyond gift: `effects.WhenPaid(cost, clause)`, `Gift.Instead`'s twin for kicker, teamwork and blight; and `checkTeamworkBlight` no longer counts a clause rewrite as a second payment component, which was the boot-time refusal #1703 hit on Cruel Alliance. No wire change: `optional_costs[i].target_mode` / `legal_targets` / `clauses` already existed and the client's `castTargetOverride` already takes the first ticked offer carrying one. **Cards (all `full`):** Too Evil to Stay Dead (caveat cleared), Cruel Alliance, Bloodchief's Thirst, Tear Asunder, Expel the Unworthy, Blood Beckoning and Divine Resilience. **Still open, each a different shape:** The Eagles Are Coming! (a delayed per-card token count), Waste Management (a player-targeted graveyard exile whose token count reads what was exiled), Galadriel's Dismissal (untargeted phasing of a target player's creatures) and Fight with Fire (a kicked divided "any number of targets"). Tracker [#887](https://github.com/krakenhavoc/cmd_and_ctrl/issues/887).
