**A mode count that reads the announced optional costs, and one that forces the higher count** (#1655, CR 601.2b / CR 603.3c / CR 700.2, [ADR 0065 amendment 2026-09-28](decisions/0065-modal-and-multi-target-clauses.md)). #1590's conditional count could only raise the maximum, off the board. `ModeSpec` now carries `RaisedMin` beside `RaisedMax`: `InsteadIf(n, cond)` is "choose both instead" with no "may", so one bullet stops being an answer; `AnyNumberIf(cond)` is "choose any number / one or more instead"; `OrUpToIf` is unchanged. The one reader is `(*Game).modeBoundsLocked` (`ModeBoundsForEffect` outside the package), which returns both bounds for a `ModeCountQuery`: the chooser, plus the optional costs announced with the choice. The cast gate validates the modes after the optional-cost choice, since CR 601.2b announces both in one step. A trigger's `mode_pick` reads the spell's own `PaidCost` while it is on the stack (a "when you cast this spell" trigger) and the permanent's `CastProvenance` after that. `game.ModeConditionOnAnnouncement` registers a key-named predicate over the query (ADR 0041: a key, not a closure); `effects.WasKicked` is the first one. For a trigger, a forced minimum asks for no more bullets than are on offer (CR 603.3c: an untargetable bullet "can't be chosen"). The hand card's `modes.min` / `modes.max` are the caster's bounds, and `modes.if_optional_paid` carries the bounds with the optional costs announced, which the client's picker switches to when a kicker is ticked. The public copy shows the printed bounds. The enumerator bounds each optional-cost announcement's mode sets by the same accessor (#544). `Register` refuses a raised minimum outside `Min..RaisedMax`. **Cards:** Inscription of Ruin, Inscription of Abundance, Depth Defiler, Prophetic Titan, Let's Play a Game and Wail of the Forgotten, all `full`. **Still open, and not this seam:** teamwork (HULK SMASH!, Go Nuts!, Atlantis Attacks, Murdock's Crusade, Widow's Bite) and blight (Pyrrhic Strike) have no optional-cost component to announce. Their mode count is one `InsteadIf` away once the cost exists.
