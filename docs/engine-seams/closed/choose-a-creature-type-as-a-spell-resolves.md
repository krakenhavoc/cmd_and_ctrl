**Choose a creature type as a spell or ability resolves** (#2382, CR 608.2, CR 205.3m) — the only creature-type chooser was the CR 614.12 as-enters one, which stamps `Card.NamedTribe`, so an instant or sorcery had nowhere to pause for the answer and then carry on. `PendingChoiceCreatureType` now has a resolution form, mirroring #742's resolution-time colour choice: `Game.QueueCreatureTypeChoiceThenForEffect(CreatureTypePrompt{…})` queues the same prompt (same vocabulary, `game.AllCreatureTypes`, same `{creature_type}` answer, same client modal and enumerator answers) with a `creatureTypeResume` continuation, and `ResolveCreatureTypeChoice` hands the canonical type to it instead of storing it. The frame is counted in `ContinuationCensus.ChoiceResumeFrames`, so a table paused on it is not a restore point, and `Clone` carries it, so undo works. A chooser who leaves the game with the prompt open runs the continuation with `""` (nobody chose; `PendingChoiceCreatureType` now declares `dropDefault`), so "each player chooses" chains finish. Card side: `effects.ChooseCreatureTypeThen`, with `permanentsOfTypeYouControl`, `creaturesOfTypeYouControl`, `notOfCreatureType` and `seatsFromController` in `creature_type_resolution.go`; `Game.SetNamedTribeForEffect` lets an as-enters card store the answer and place counters in one continuation. Changelings count for every type through `Card.HasSubtype`. **7 cards:** Distant Melody, Kindred Dominance, Raise the Palisade, Banner of Kinship, Patriarch's Bidding (one prompt per seat, caster first), Tribal Unity and Kindred Charge. Haunting Voyage (foretell and an up-to-two pick), Kindred Summons (reveal until X) and Reflections of Littjara (copy as cast) stay out.
