**Magecraft's "or copy"** (#2090, CR 207.2c / 707.10 / 707.10b / 707.12) — every spell copy put on the stack is made by `createSpellCopyLocked` (`game/spell_copy.go`), behind `CopySpellForEffect` and `CopyLastKnownSpellForEffect`, so Twincast, Reverberate, storm, casualty, Doublecast and a Chain's "copy this spell" all emit `EventSpellCopied` (Actor the copy's controller, CardID the copy, Source the original) and no `EventCast`, because a copy is created, not cast (CR 707.10). A copy of a card cast from another zone (Mizzix's Mastery, Spellweaver Volute, a prepared card) is cast (CR 707.12): it emits `EventCast` and nothing as the card copy is made, so it counts once, as a cast, and a card copy nobody casts counts nothing. `effects.Magecraft(label, effect)` is the shared trigger, watching both events through `instantOrSorceryCastOrCopiedByYou`, and it can be wrapped in `Targeting`. "You" is the copy's controller (CR 707.10b): an opponent's Reverberate on your spell triggers their magecraft, not yours. Tests pin a cast, a copy, one trigger per storm copy, one per cast copy and none for an opponent's copy. **Cards:** Extus, Oriq Overlord // Awaken the Blood Avatar (Full), whose Avatar token carries its own attack trigger (`token:avatar-blood`); Archmage Emeritus, Sedgemoor Witch and Storm-Kiln Artist (already Full since #3172) now use the shared trigger.
