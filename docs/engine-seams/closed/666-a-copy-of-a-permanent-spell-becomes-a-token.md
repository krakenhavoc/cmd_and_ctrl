**A copy of a permanent spell becomes a token** (#666, [ADR 0043 amendment](decisions/0043-copy-effects.md)): `resolveTopOfStackLocked`'s refusal (an `EventEffectError` and a vanished copy) is replaced by the rule. `resolvePermanentSpellCopyLocked` (`game/spell_copy.go`) takes the copy off the stack first — the creation can pause on a CR 616 prompt — then creates one token from the spell's copiable values through `CreateTokensThenForEffect`, [ADR 0061](decisions/0061-token-creation-and-discard-are-replaceable-events.md) / #923's ONE token-creation path. Everything else follows: the CR 701.7b window opens so **Doubling Season doubles it**, the token takes the ordinary battlefield entry so enters-tapped, enters-with-counters, `EventETB` and `fireETBHookLocked` all reach it, and `PrintedValues.MakeToken` stamps the Token supertype so CR 704.5d removes it from any zone but the battlefield and a bounce cannot make it a card. The face is settled as the ordinary permanent branch settles it, so CR 707.10g (a copy of a double-faced permanent spell is double-faced) falls out. `CopySpellForEffect` and `effects.CopySpell` gain an `Except` taking the same `*game.PrintedValues` an entering permanent's except clause edits, applied where the copy is created so no closure has to cross the CR 707.10c re-target prompt. **What travels and what does not (CR 707.2):** the token is the copiable values plus the Token supertype, so `StackItem.Foretold` and `Card.FaceDownKind` (#987) are absent — a copy is created, not cast, and cannot be born face down — while `PaidCost.OptionalCosts` (#988) is NOT a characteristic but still reaches the token, because CR 707.10b copies the choices made when casting and CR 400.7d carries them onto the permanent: `resolvePermanentSpellCopyLocked` stamps `Card.PaidOptionalCosts` onto the template exactly as the ordinary permanent branch stamps it, so a Double Major on a twice-kicked Wolfbriar Elemental makes a token that creates its own two Wolves. **Cards:** Double Major, Full — the first card in the catalog that copies a permanent spell at all. Still open and NOT closed by this: copying an ABILITY (Lithoform Engine's other halves, Strionic Resonator — the "Ability-copy" row above); a token copy of an AURA spell enters attached to nothing and dies to CR 704.5m; X is not re-derived for the token.
