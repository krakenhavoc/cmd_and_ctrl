**Counter-placing costs join the CR 614 replacement window** (#1710, CR 614.16 / CR 606.4, [ADR 0073 amendment 2026-09-28](decisions/0073-optional-additional-costs-and-the-cast-gate.md)). Devoted Druid's "put a -1/-1 counter on this creature" cost and a planeswalker's loyalty cost (both the catalogued CR 602 path in `activated.go` and the `ActivateLoyalty` sandbox verb in `mutations.go`) used to write the counter-map mutation directly, on the reasoning that a counter-doubling replacement applies only to a counter placed by an EFFECT (CR 614.16) — true of Doubling Season, but it also skipped every replacement that names no effect at all, which CR 614.16 does not exclude. `game.payCostCounterLocked` (`counter_cost.go`) generalises `blightLocked`'s #1703 pattern off the blight-specific call: it opens the window with `ReplacementEvent.CounterFromCost` set and settles without pausing (a cost is paid in one indivisible step, CR 601.2h / 602.2b). Doubling Season's existing `CounterFromCost` gate still declines both; **Vizier of Remedies now reduces the Druid's cost to zero counters** (the long-standing infinite-mana combo, confirmed against Gatherer's Doubling Season ruling that a loyalty ability's cost is "put on as a cost, not as an effect" the same way), **Winding Constrictor adds one to the Druid's placement**, and **Vorinclex, Monstrous Raider doubles a `+1` loyalty ability to `+2`** — all three previously inert. The ability still resolves even when a replacement erases its counter entirely (CR 118.3 was already checked before payment); `PaidCost.CountersAdded` now records what actually landed instead of the printed number. A negative loyalty delta (a "-N" ability) is unaffected, since every registered placement replacement gates on a positive `CounterDelta` (CR 614.1 — a removal is not a placement). **Cards:** Vizier of Remedies (new, `full`) joins Winding Constrictor and Vorinclex, Monstrous Raider, both already catalogued.
