**Rad counters** (#2042, CR 728.1, CR 728.1a) — a player could be given rad counters (`game.CounterRad`, and proliferate knew them), but they did nothing, so no card that gives them could be added. `radTriggers` (`game/rad_counters.go`) is CR 728.1's inherent trigger, a sourceless listener like the monarch's and speed's: when the active player's precombat main phase begins (`EventBeginPrecombatMain`, the first main phase only, CR 505.1a) and they have a rad counter, it queues the keyed `rad/mill` item, controlled by them and with no source; it uses the stack. The condition is an intervening if (CR 603.4), read again on resolution, and the count milled is the count then, so a proliferate in response mills one more. It mills through `MillToZoneThenForEffect`, so a card a replacement sent elsewhere was not "milled this way" (CR 400.7) and a short library mills what it has (CR 701.17b). The nonland cards milled cost that much life as one loss, then that many rad counters come off, also when the loss was replaced. The loss is "from radiation" (CR 728.1a): `ReplacementEvent.LifeFromRadiation` marks it for a replacement and `Event.FromRadiation` marks the landed `EventChangeLife` (additive in schema 7). Card helpers: `effects/rad_counters.go`. The client already showed a player's rad counters. **Cards (7, all Full):** Bloatfly Swarm, Nuclear Fallout, Contaminated Drink, Megaton's Fate, Vexing Radgull, Feral Ghoul and Glowing One. **Still open:** the other 15 Commander-legal rad-counter cards are on the `rad-counters` row's Waiting list (#2809), which says what each needs.
