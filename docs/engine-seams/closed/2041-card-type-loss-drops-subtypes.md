title: "Losing a card type loses its subtypes"
date: 2026-10-15
issues: [2041]
---
**Losing a card type loses its subtypes** (#2041, CR 205.1a / 205.3d / 613.1d) — the layer pass applies CR 205.1a to every layer-4 effect (`game/card_type_loss.go`): `applyTypeChange` notes which subtype lists the object's card types allow before the effect and after it, and drops the subtypes of every list the effect closed. `RemoveTypesMod`, a Theros God's devotion clause, impending, reconfigure and any catalog closure that rewrites the type list all lose the subtypes their removal took, and none of them has to remember to. A subtype stays while any remaining type allows its list: creature types with Creature or Kindred (Tribal), land types with Land, and likewise artifact, enchantment, planeswalker (CR 205.3j, newly listed), spell and battle types. "Is every creature type" goes with the creature list. The drop happens in the removing effect's own timestamp slot (CR 613.7), so a later "becomes an artifact creature" makes the object a creature again without the creature types the removal took, and the next pass after the removal ends rebuilds them. The CR 613.8 dependency probe applies it too. The gaining half of CR 205.3d (an object can't gain a subtype no type allows) is not enforced by the pass. **Cards:** Weeping Angel (Full). `notACreature` now removes only the type and leaves the subtypes to the pass, and Erebos, Bleak-Hearted, which kept God while it wasn't a creature, now loses it.
