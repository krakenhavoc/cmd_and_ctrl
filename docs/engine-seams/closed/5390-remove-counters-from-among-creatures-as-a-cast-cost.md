**Remove counters from among creatures as a cast cost** (#5390; CR 601.2b, 601.2h, 118.3) — "remove N counters from among permanents you control" was an *activation* cost only (`AbilityCost.RemoveCounters`, `activate_ability`'s `counter_source_ids`), so a graveyard cast whose extra cost spreads over several creatures' counters had no shape. `game.AlternativeCost.RemoveCounters` now carries the same `CounterRemovalCost` on a cast: `AlternativeCostPayableLocked` withholds the offer from a caster whose creatures hold fewer than N counters in all (`CounterCostPayable`, CR 118.3), announce validates the payment through the activation's own `validateCounterRemovalLocked` with the spell as the source (exactly N, each (permanent, kind) once, the caster's own matching permanents, any kinds, split as the caster chooses), and `payCounterRemovalLocked` takes them off with the spell on the stack, first of the board costs (CR 601.2h's any order, so a creature both drained and sacrificed pays both), recording `PaidCost.CountersRemoved`. A payment sent with no counter component to pay is refused. The wire is additive: `cast_spell` takes `counter_source_ids` / `counter_counts` / `counter_kind` / `counter_kinds` (activate_ability's names), `alternative_costs[i]` carries the activation's counter fields (`counter_cost_n`, `counter_cost_among`, `counter_cost_label` public with the offer; `counter_cost_options` per viewer), the client opens the existing counter picker after the offer is chosen, and the enumerator offers one payment by the activation's rule (`counterPaymentChoices`), priced on `MoveCost.counters`. `effects.CastFromGraveyardByRemovingCounters` builds the graveyard offer (retrace's model: the printed mana cost, no exile clause); `Register` (`checkAltCostRemoveCounters`) holds the component to a fixed "from among …" count with no card component beside it. The parked-cast snapshot gains the four param fields (additive). **Cards now Full:** Quilled Greatwurm.
