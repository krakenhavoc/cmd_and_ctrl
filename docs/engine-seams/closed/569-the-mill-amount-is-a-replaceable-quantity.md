**The mill amount is a replaceable quantity** (#569, [ADR 0013 §5u](decisions/0013-replacement-effects.md)): "If an opponent would mill one or more cards, they mill twice that many cards instead" (Bruvac the Grandiloquent) replaces the NUMBER, once, before anything leaves the library, and `ReplacementEventKind` had no kind for it. What was NOT missing is the per-card window, and the claim that it was circulated on three status comments and a PR body: every milled card has gone through `routeCardToZoneLocked` since #529, so Leyline of the Void sees each one and a milled commander is offered the command zone (#539). One `game.RepEventMill{MillPlayer, MillCount}` now opens once per mill INSTRUCTION, on the shape `RepEventCreateTokens` (ADR 0061) and `RepEventKeywordAction` (#976) already use — so a mill opens two kinds of window in sequence, the amount then the per-card exit. It opens only for a mill the rules can replace the amount of: a GRAVEYARD destination (CR 701.13a defines the keyword action by where the cards go, so "exile the top N cards of your library" is not a mill) and a POSITIVE count (an unbounded `until` run names no number). The count is the INSTRUCTION's, not the library's — CR 701.13b's "as many as possible" clamp stays in `millPlanLocked`, after the window. Card-side it is `MillBecomes{Count, Scope, Label}` with `OpponentsMillTwice` and `OpponentsMillPlus(n)` as the named wrappers. Both mill forms can now PAUSE before any card moves, carrying the destination, the `until` predicate and the caller's continuation on `millTail`; a cancelled, zeroed or abandoned mill runs that continuation with an empty list. **Cards:** Bruvac the Grandiloquent and The Water Crystal, both `full` — ×2 and +4, the pair CR 616.1's ordering prompt is about, and the first printed board on which #982's affected-player rule is observable (the prompt goes to the opponent being milled, not to the player who controls both). Combustible Gearhulk moves to the continuation form because it read the fire-and-forget slice. A surveil's graveyard leg is deliberately NOT a mill (CR 701.14a) and opens no amount window.
