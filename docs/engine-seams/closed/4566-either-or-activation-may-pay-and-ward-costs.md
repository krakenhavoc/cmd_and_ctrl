**Either/or costs on an activated ability, a may-pay and a ward** (#4566, [ADR 0100 amendment 2026-10-30](decisions/0100-delve-either-or-and-variable-sacrifice-costs.md), CR 602.2b / 601.2b / 601.2h / 118.3 / 118.12 / 603.12 / 702.21a): "sacrifice an artifact or discard a nonland card" could be a spell's additional cost but not anything else. Three changes add it elsewhere. An **activated ability's cost** has `game.AbilityCost.Either`, plain-data branches built with `effects.OrCost(SacrificeBranch, DiscardBranch)`. The branch is announced as `activate_ability.cost_branch`, is required on a branched row, and is folded into the ordinary clause by `game.ChosenAbilityCost` before any gate. The enumerator offers one row per payable branch, the view sends `cost_branches[]`, and the client asks for the branch first. A **resolution-time "you may"** has `effects.MayPay.Pay`, which carries ADR 0187's either payment (`effects.SacrificeAnArtifactOrDiscard`, with `PayAction.Nonland`). It asks nobody when no branch can be paid. A **ward** has `effects.WardEither`, which uses the guarded counter-unless-paid prompt carrying that either payment, with a mana branch (`game.PayActionMana`). **Cards:** Bullseye, Death Dealer; K'un-Lun Warrior; Contract Hero; Vision of Love; Titania, Rugged Rumbler (all Full).
