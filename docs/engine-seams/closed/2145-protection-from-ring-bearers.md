**Protection from Ring-bearers** (#2145): "protection from Ring-bearers" (Lord of the Nazgûl) is `ProtectionQualityRingBearer`. A Ring-bearer is a designation (CR 701.54b), so the source snapshot carries it as `Characteristic.SourceRingBearer`, set when the source is its controller's Ring-bearer (CR 701.54e) and, for a source that has left the battlefield, from `PermanentInfo.RingBearer`. Wire token `ring_bearer`. Shipped on **Lord of the Nazgûl**.
