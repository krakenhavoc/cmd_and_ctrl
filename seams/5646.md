## Replace damage that would remove a planeswalker's last loyalty counter

Size: **small**. 1 card waits on it.

**Deification** {1}{W} — Enchantment (MAT)
> As this enchantment enters, choose a planeswalker type.
> Planeswalkers you control of the chosen type have hexproof.
> As long as you control a creature, if damage dealt to a planeswalker you control of the chosen type would result in all loyalty counters on it being removed, instead all but one of those counters are removed.

**The clause.** As long as you control a creature, if damage dealt to a planeswalker you control of the chosen type would result in all loyalty counters on it being removed, instead all but one of those counters are removed.

**The gap.** Damage to a planeswalker removes loyalty inside applyDamageToPermanentLocked (server/internal/game/damage_tail.go, the CR 120.3c / 306.8 split) with no window that can change the RESULT of the damage for a planeswalker; the nearest hook is damageResultAsThoughLocked (damage_as_though.go, wither as-though). The damage is still dealt in full (lifelink, 'dealt damage' triggers), only the counter removal is capped, so it is not a prevention. Needs a static-declared cap read as the damage lands, keyed on the chosen planeswalker type and 'you control a creature'. The 'choose a planeswalker type' prompt and the hexproof static have precedent (leori_sparktouched_hunter.go, game.PlaneswalkerTypes).

**Checked.** grep -rliE 'would result in all loyalty counters|all but one of those counters' in server/internal/cards/effects/ -> no file. grep 'loyalty' in server/internal/game/damage*.go -> only the CR 120.3 comment in damage_tail.go. grep 'choose a planeswalker type' -> leori_sparktouched_hunter.go (the choice exists). Replacement event kinds in replacements.go cover Move, Mill, ETB, CreateTokens, Counter (placement), ProduceMana, Discard, Draw, Life, Damage: none for counters REMOVED by damage.
