Size: **small**. 2 cards wait on it.

**As planned for Innistrad: Crimson Vow:** Return a card transformed, attached to a named host

**The clause (VOW plan).** When enchanted creature dies, return this card to the battlefield transformed under your control attached to target opponent.

**The gap (VOW plan).** game.ReturnFromGraveyardTransformedForEffect(cardID, controller, tapped, counters) (game/transform.go:565) has no host parameter. Without one the CR 303.4f entry choice (game/aura_host.go) asks the controller to pick any player for the back face's 'Enchant player', which is untargeted and lets the Curse go on yourself: stronger and different from printed. Needs an AttachedTo (a TargetRef of kind player) on the transformed-return path, as ZoneEntryOptions.AttachedTo / ReturnFromGraveyardTogether.AttachedTo already give the untransformed paths, and CR 303.4i when the host is illegal.

**Checked (VOW plan).** grep -n 'AttachedTo' game/transform.go game/exile_return_transformed_counter.go: 0 hits. grep -liE 'attached to target opponent|transformed under your control attached' cards/effects: 0 files. docs/adding-cards.md 'Auras put onto the battlefield without being cast (#3158)' lists AttachedTo only on SearchLibrary, ReturnFromGraveyardTogether, PutOntoBattlefieldTogetherKeyedForEffect and TokenEntryOptions.

**As planned for Innistrad: Midnight Hunt:** Return a card to the battlefield transformed and attached to a target

**The clause (MID plan).** When this creature dies, return it to the battlefield transformed under your control attached to target creature or planeswalker an opponent controls.

**The gap (MID plan).** The back face (Strangling Grasp) is an Aura, so the card must enter back face up already attached to the trigger's target (CR 712.14a, CR 303.4f names the case where the effect does specify the host). game.ReturnFromGraveyardTransformedForEffect(cardID, controller, tapped, counters) has no host argument, and ReturnCard has Transformed but not EntersAttachedTo (that field is on SearchLibrary only). Add a host to the transformed return and to ReturnCard; an illegal host leaves the card in the graveyard.

**Checked (MID plan).** grep -rniE 'transformed under your control attached|transformed.*attached|attached.*transformed' effects game: 0. grep 'Transformed: *true' effects: convert.go, garland_knight_of_cornelia.go, the Ojer gods, optimus_prime_hero.go (none is an Aura back face). ls effects | grep -E 'accursed_witch|radiant_grace': neither is in the catalog. EntersAttachedTo: effects/primitives.go:1204, game/effect_api.go:2298 (search only).
