**The clause.** Domain — ... for each basic land type among lands you control. / This ability costs {1} less to activate for each basic land type among lands you control.

**The gap.** Not missing engine work: the count is written twice as private helpers, domainCountYouControl (leyline_binding.go:38, takes a CostQuery) and rfCreatureBBasicLandTypesAmong (reality_fracture_fra_creature_b_helpers.go:134). 21 cards of this set need it in three shapes: a spell or activation cost reduction, a characteristic-defining power/toughness, and a count read at resolution. It is listed as a seam item only so ONE worker exports one helper (an Amount for effects.Do, a CostQuery reader, a P/T static with a Label) before batches 10, 11 and 14 use it, instead of three batches each writing their own. Move the two existing callers onto it. These seven cards cover each shape. Llanowar Greenwidow's granted 'If this permanent would leave the battlefield, exile it instead' has 6 precedents (grep 'would leave the battlefield, exile it instead').

**Checked.** grep 'basic land types? among lands' -> attack_tax.go, leyline_binding.go; grep 'func.*[Dd]omain|func.*BasicLandType' -> the two private helpers above plus land-type setters; 'costs {1} less to activate for each' -> 19 files (cost_modifier.go, boseiju_who_endures.go).
