## Let cost modifiers recognise a ninjutsu ability

Size: **small**. 1 card waits on it.

**Silver-Fur Master** {U}{B} — Creature — Rat Ninja (NEO)
> Ninjutsu {U}{B} ({U}{B}, Return an unblocked attacker you control to hand: Put this card onto the battlefield from your hand tapped and attacking.)
> Ninjutsu abilities you activate cost {1} less to activate.
> Other Ninja and Rogue creatures you control get +1/+1.

**The clause.** "Ninjutsu abilities you activate cost {1} less to activate." (Silver-Fur Master)

**The gap.** Activation cost modifiers pick a keyword by a bit on the priced ability (game/cost_modifier.go:355-373: Exhaust, Boast, PowerUp; effects AnEquipAbilityCost/ABoastAbilityCost/APowerUpAbilityCost). effects/ninjutsu.go says 'Nothing in the engine knows the word ninjutsu', so there is nothing to match on but the label, which the code forbids. Expect a Ninjutsu bit set by effects.Ninjutsu(), an ANinjutsuAbilityCost predicate, and a check that a hand-zone activation is priced through the same modifier path (commander ninjutsu included).

**Checked.** git grep -i 'ninjutsu abilities|NinjutsuCost|ninjutsu.*cost.*less' internal/game and effects: 0. 'abilities you activate cost' in effects: boast.go:76, bureau_headmaster.go (EquipAbilitiesYouActivateCostLess), dragonkin_berserker.go: the sibling pattern to copy. 'Ninjutsu|Keyword' in game/cost_modifier.go: only exhaust/boast/power-up bits.
