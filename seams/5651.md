## Mark backup abilities on the stack so a trigger can see one targeting a creature

Size: **small**. 1 card waits on it.

**Mirror-Shield Hoplite** {R}{W} — Creature — Human Soldier (MOM)
> Vigilance
> Whenever a creature you control becomes the target of a backup ability, copy that ability. You may choose new targets for the copy. This ability triggers only once each turn.

**The clause.** "Whenever a creature you control becomes the target of a backup ability, copy that ability. You may choose new targets for the copy. This ability triggers only once each turn."

**The gap.** EventBecomesTarget carries StackItemID and TargeterKind (spell / activated / triggered) but nothing identifies the triggered ability as backup; Backup() in soc_b6_helpers.go is an ordinary WhenThisEnters whose only mark is its label text. Expect a keyword tag on TriggeredAbility/StackItem set by Backup(), then CopyAbility{ItemID} (ability_copy.go) does the copy; the copy must still grant the ORIGINAL source's abilities.

**Checked.** grep 'becomes the target of a backup ability', 'backup ability' effects: 0; grep IsBackup|AbilityTag|AbilityKeyword game: 0; ability copy exists (ability_copy.go, 8 files with 'copy that ability. You may choose new targets'); once-per-turn: docs/adding-cards.md 'This ability triggers only once' (#5245).
