## Let a spell planeswalk or make chaos ensue after a vote, and add the planar-die extra roll

Size: **medium**. 6 cards wait on it.

**Path of the Animist** {3}{G} — Sorcery (MOC)
> Search your library for up to two basic land cards, put them onto the battlefield tapped, then shuffle.
> Will of the Planeswalkers — Starting with you, each player votes for planeswalk or chaos. If planeswalk gets more votes, planeswalk. If chaos gets more votes or the vote is tied, chaos ensues.

**Path of the Enigma** {4}{U} — Sorcery (MOC)
> Target player draws four cards.
> Will of the Planeswalkers — Starting with you, each player votes for planeswalk or chaos. If planeswalk gets more votes, planeswalk. If chaos gets more votes or the vote is tied, chaos ensues.

**Path of the Ghosthunter** {X}{1}{W} — Sorcery (MOC)
> Create X 1/1 white Spirit creature tokens with flying.
> Will of the Planeswalkers — Starting with you, each player votes for planeswalk or chaos. If planeswalk gets more votes, planeswalk. If chaos gets more votes or the vote is tied, chaos ensues.

**Path of the Pyromancer** {4}{R} — Sorcery (MOC)
> Discard all the cards in your hand. Add {R} for each card discarded this way, then draw that many cards plus one.
> Will of the Planeswalkers — Starting with you, each player votes for planeswalk or chaos. If planeswalk gets more votes, planeswalk. If chaos gets more votes or the vote is tied, chaos ensues.

**Path of the Schemer** {4}{B} — Sorcery (MOC)
> Each player mills two cards. Then you put a creature card from a graveyard onto the battlefield under your control. It's an artifact in addition to its other types.
> Will of the Planeswalkers — Starting with you, each player votes for planeswalk or chaos. If planeswalk gets more votes, planeswalk. If chaos gets more votes or the vote is tied, chaos ensues.

**Ichor Elixir** {4} — Artifact (MOC)
> If you would roll one or more planar dice, instead roll that many planar dice plus one and ignore one.
> {T}: Add {C}{C}.

**The clause.** "Will of the Planeswalkers — Starting with you, each player votes for planeswalk or chaos. If planeswalk gets more votes, planeswalk. If chaos gets more votes or the vote is tied, chaos ensues." / "If you would roll one or more planar dice, instead roll that many planar dice plus one and ignore one."

**The gap.** 'Chaos ensues' exists only as the planar die's chaos face (WheneverChaosEnsues watches EventRollDie with PlanarFaceChaos); a resolving spell saying 'chaos ensues' (CR 311.7, 901.9b) has no emitter, so chaos abilities cannot be triggered by an effect. PlaneswalkForEffect exists (game/planeswalk.go) and voting exists (ADR 0146), so the vote is composition. Ichor Elixir needs a static replacement on planar-die rolls; game/dice_roll.go has only the one-shot ModRollExtraDieIgnoreOne. Also decide and state what these clauses do in a game with no planar deck (expected: nothing).

**Checked.** grep -i 'chaos ensues|ChaosEnsue' game/*.go: only the die comment in planechase_die.go; planes_b1_helpers.go comment 'No card of the catalog yet says chaos ensues as an effect'; grep 'will of the planeswalkers' effects: 0; grep 'plus one and ignore' effects: 0; 'planeswalk.' as an effect only in bad_wolf_bay.go / effects_planechase.go.

**Owner question.** The five Path cards' "Will of the Planeswalkers" and Ichor Elixir only do anything in a game with a planar deck. Planechase is in the engine (ADR 0216), so they are planned as a seam; in an ordinary Commander game the vote happens and nothing follows. If that is not worth a strong-model slot, close this and the six cards wait.
