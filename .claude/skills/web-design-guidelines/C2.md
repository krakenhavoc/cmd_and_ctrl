## C2 notes

- Sentence case is the project's style. A Title Case finding in `rules.md` is not a defect here.
- The client is Svelte 5, not React. Read React-specific rules (`onClick`, `<Link>`,
  hooks, `key`) as their Svelte equivalent (`onclick`, `<a href>`, `$effect`, keyed `{#each}`).
- The client is a client-only SPA with no server rendering, so the hydration rules do not apply.
- The game and table screens follow the table's own conventions (dense, pointer-driven,
  drag and drop, hotkeys). Report against them only where a rule is plainly about
  accessibility, not density or layout.
- C2's own design system is in `DESIGN.md`; where it and a rule disagree, DESIGN.md wins.
