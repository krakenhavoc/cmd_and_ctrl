# shards.txt — the frozen range table of the split effects tree (#5906, ADR 0225).
#
#   card <shard> <from>   a card file goes to internal/cards/effects/cards/<shard>/ (package cards<shard>)
#   test <id>    <from>   a _test.go file goes to internal/cards/effects/tests/<id>/ (package tests<id>)
#
# A file belongs to the last row of its kind whose <from> is less than or equal
# to its lower-cased file name; the first row of each kind starts at 0. So
# monk_gyatso.go is a card of shard mi (mi <= monk_gyatso.go < n), and
# monk_gyatso_test.go is a test of package m.
#
# The rows are frozen: they change only in a PR whose purpose is to change them
# (to split a shard that has passed about 1,000 card files or 300 test files),
# never as a side effect of adding a card. Such a PR moves the files with
# scripts/split-effects.sh --check / --place and regenerates the aggregator.
# server/internal/docsguard checks that every file sits where this table puts
# it, and scripts/split-effects reads it to place a file.
#
# Sized on develop at 2af192538 (2026-11-19, 17,223 card files and 2,945 test
# files) for at most 600 card files and 150 test files a package; the comment
# on each row is the count and range then.
